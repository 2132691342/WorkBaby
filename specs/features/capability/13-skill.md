# 13 · 技能（Skill）

技能是一份 `SKILL.md`：YAML frontmatter + Markdown 正文，可选带 `scripts/`。
它把「一类任务该怎么做」固化成可复用的说明，**按需注入**而不是常驻上下文。

## 1. 文件格式

```markdown
---
name: review
description: 代码审查
when_to_use: 审查|review|检查改动
allowed_tools: file_read, file_grep
version: 1
---
正文：步骤、约定、输出格式
```

| 字段 | 作用 |
|---|---|
| `name` | 唯一名 |
| `description` | 一句话职责（界面展示） |
| `when_to_use` | 触发词（`|` 分隔），用于确定性匹配 |
| `allowed_tools` | 命中后本轮的工具白名单 |
| `version` | 版本（更新判定） |

## 2. 来源与两级目录

| 来源（`SourceKind`） | 位置 | 说明 |
|---|---|---|
| `builtin` | 编译期嵌入（`assets/skills`） | 对用户只读（改/删均拒绝） |
| `download` | 导入（粘贴 / zip） | 可更新与删除 |
| `custom` | `{home}/skills` 与 `<工作区>/.workbaby/skills` | 用户自建 + 目录发现 |

### 两级叠加

| 根 | 生效范围 |
|---|---|
| `{home}/skills` | 所有会话可用 |
| `<工作区>/.workbaby/skills` | 仅该工作区可用，**同名覆盖全局** |

切换工作区时整根摘除上一工作区的技能，被覆盖的全局版本自动恢复。

### 一致性维护

| 情况 | 处理 |
|---|---|
| 磁盘上删除的技能 | 从注册表摘除；UI 自建技能永不被摘除（`SourceRef` 为空） |
| 已下架的内置技能 | `SyncBuiltin` 判定「本次未被 `LoadBuiltin` 读到且 `SourceRef` 属内置来源」即删除（否则会永久占着技能位且关不掉） |
| 用户启停状态 | 落 `skills.Enabled`，重扫时继承，不会被重置 |

## 3. 内置技能

内置技能只解析 `SKILL.md`——同级的 `references/`、`scripts/` 等资源**不会被加载**。
因此内置技能必须**自包含**：正文里不得链接 `references/*.md`，也不得调用 `scripts/*.py`。

要带脚本的技能放到 `{home}/skills/{name}/`：那里的 `scripts/` 会随 `SKILL.md` 一起入库，
`run_skill_script` 才能执行。

| 内置技能 | 用途 |
|---|---|
| `office-docs` | 用内置 Python 处理 Word / Excel / PPT / PDF（依赖安装 + 格式要点 + 标准流程） |
| `create-skill` | 按约定编写新技能：格式、触发词、自包含约束与落地路径 |
| `frontend-design` | 前端界面与组件的设计实现指引 |

## 4. 匹配与注入

**匹配是确定性的**：`Registry.Match(content)` 取命中触发词最长者；等长按名字典序
（避免 map 遍历顺序随机导致同输入不同技能）。

**注入流程**（能力注册表的 Preload 通道）：

| 步 | 行为 |
|---|---|
| 1 | run 前按用户输入匹配技能 |
| 2 | 命中则把技能正文作为 `Section` 注入上下文（`Order=60`） |
| 3 | `allowed_tools` 作为本轮工具白名单（只能收缩不能扩权） |
| 4 | 事件 `chat:skill` 通知前端（名称 / 来源 / 版本 / 工具白名单 / 注入字数） |

脚本执行走 `run_skill_script`（解释器固定映射，2 分钟超时）。

## 5. 取舍

| 取舍 | 优势 | 代价 |
|---|---|---|
| 技能正文按需加载（元数据常驻） | 上下文预算不被技能正文挤占 | 模型需先「读」才知道细节，多一次工具调用 |
| 确定性匹配（非语义） | 同输入必得同结果，可预测 | 触发词需人工维护 |
| 两级叠加（全局 → 工作区同名覆盖） | 团队共享与个人定制并存 | 覆盖关系需要解释（设置页给出说明） |
| 内置技能自包含约束 | 不依赖运行时资源加载，行为可预测 | 富资源技能必须放到用户目录 |
| 用户启停状态持久化 | 重扫不重置用户意图 | 多一份状态需要与磁盘状态对齐 |
