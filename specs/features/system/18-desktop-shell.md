# 18 · 桌面壳：窗口、桌宠、托盘与单实例

## 1. 窗口形态

两种形态共享同一前端上下文与状态（**单窗口切换**，非多窗口）：

| 形态 | 尺寸 | 特性 |
|---|---|---|
| 主窗口态 | ≥960×640 | 完整三栏布局 |
| 桌宠态 | 260×300 | 可置顶、可移动、非命中区域鼠标穿透 |

切换时记忆主窗口位置与尺寸并在切回时还原。托盘菜单「召唤·收起桌宠」直接切换形态。

### 为什么单窗口

多窗口需要 Wails v3；单窗口共享同一前端上下文（store / SSE 连接 / 主题）能省掉一套跨窗口状态同步。

## 2. 桌宠

### 状态机

`pet.Controller` 状态：`idle / happy / working / sleeping`

| 事件 | 迁移 |
|---|---|
| `agent.run.start` | → working |
| `agent.run.done` | → happy，3 秒后自动回 idle |
| `agent.error` | → idle |
| 用户闲置 30 分钟 | → sleeping |
| 用户活动 | → idle |

状态变化回调 emit `pet:state`，前端据此切换形象。状态相同不重复回调。
订阅端容错：缺事件时回落 idle。

### 形象

| 项 | 实现 |
|---|---|
| 内置形象 | 编译期嵌入（`assets/workbaby.png`），首次启动播种为默认选中 |
| 用户上传 | magic number 识别 png/jpg/gif/webp（防扩展名伪装），≤5MB，落盘 `{home}/sprites/{id}{ext}` |
| 读取 | 经 `/files/sprites/{id}`（WebView2 不能直接读 `file://`，需要本地文件服务）；上传时后端把本地图片转成 data URL |

### 点击穿透

桌宠态下用 Win32 `CreateRectRgn` + `CombineRgn` 设置命中区域（最多 64 个矩形）：
未覆盖区域鼠标穿透到下面的窗口；清空区域即恢复可点击。

命中判定依赖前端上报矩形（存在平台 / DPI 差异）。

## 3. 系统托盘

`internal/tray`（Win32 原生实现，非 Windows 提供空实现）。

| 菜单项 | 行为 |
|---|---|
| 显示 / 隐藏主窗口 | 切换可见性 |
| 召唤 · 收起桌宠 | 切换形态 |
| 退出 | 真正退出（区别于关闭窗口） |

关闭到托盘可配置（设置页）。

## 4. 单实例保护

`internal/singleinstance`：命名互斥 + 本地 TCP IPC。

| 步 | 行为 |
|---|---|
| 1 | 尝试创建命名互斥体 |
| 2 | 已存在（第二次启动）→ 通过本地 TCP 把参数（如文件路径）发给已有实例 |
| 3 | 已有实例收到后唤起窗口并打开对应文件/会话 |
| 4 | 新进程退出 |

配合文件关联（`.md / .txt / .pdf` 双击唤起）与 `app:open-file` 事件。

## 5. 双通道与系统能力

| 通道 | 承载 |
|---|---|
| HTTP `/api/v1` + SSE | 全部业务 API 与实时事件（可浏览器调试、可 curl 复现、可重放） |
| Wails 绑定 | 仅系统能力：文件对话框、打开外链、剪贴板、托盘、窗口控制、形象资产读写 |

`app:*` 事件经 `bindEventBridge` 转发到 Wails；`chat:*` **不转发**——SSE 已覆盖，
避免每条增量在 run goroutine 上多做一次序列化与 IPC。

## 6. 生命周期

| 阶段 | 动作 |
|---|---|
| 启动 | 单实例检查 → `api.Handler.Startup`（装配）→ 启动内嵌 HTTP Server（随机端口）→ 发 `app:ready{server_port}` |
| 运行 | 托盘常驻；窗口可关闭到托盘 |
| 退出 | 关闭 MCP 子进程 → 停止 worker → 保存配置 → 释放互斥体 |

## 7. 取舍

| 取舍 | 优势 | 代价 |
|---|---|---|
| 桌宠是主窗口的一种形态（单窗口切换） | 无需多窗口架构；共享同一前端上下文与状态 | 无法与主窗口同时显示 |
| 事件驱动状态机（订阅 `chat:*`） | 姿态与 Agent 状态天然一致，无需额外轮询 | 依赖事件时序（订阅端需容错） |
| 点击穿透 + 命中区域上报 | 不遮挡用户操作 | 命中判定存在平台 / DPI 差异 |
| 形象资产本地托管（`/files/sprites`） | 与头像、聊天背景同源 | 依赖本地 HTTP 服务可用（未就绪时静默回退内置） |
| 托盘 Win32 自研 + 非 Windows 空实现 | 无 CGO、无额外依赖；跨平台编译不破 | 仅 Windows 可用托盘 |
| 单实例走本地 TCP IPC | 可传参（文件路径）并唤起已有实例 | 需要端口与互斥体两套机制配合 |
