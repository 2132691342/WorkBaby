# 14 · MCP（外接工具服务器）

MCP（Model Context Protocol）用于外接任意工具服务器。当前支持 `stdio` transport。

## 1. 客户端

`mcp.StdioClient`：JSON-RPC 2.0 over 子进程 stdin/stdout。

| 参数 | 值 |
|---|---|
| 协议版本 | `2025-06-18` |
| 单行上限 | 1MB |
| 调用超时 | 60s |
| stderr | 保留尾部 4KB（排障用） |

```go
type Client interface {
	Initialize(ctx) (*ServerInfo, error)
	ListTools(ctx) ([]ToolDef, error)   // 跟进 nextCursor 分页
	CallTool(ctx, name, args) (*Result, error)
	Close() error
}
```

`Done()` 通道在子进程死亡时关闭，`Manager` 据此自动注销其工具——
死进程的工具不会留在注册表里被模型调用到。

## 2. 管理器

`mcp.Manager` 按 `fingerprint = command + args + env` **增量对齐**：

| 变化 | 动作 |
|---|---|
| 指纹变化 | 重启该服务器 |
| 新增 | 启动 |
| 删除 | 停止 |

启动流程：`Dial → Initialize → 监听 Done → ListTools → 逐个注册`。

服务器名强制 `^[A-Za-z0-9_-]{1,32}$`（要进工具名）。
启动失败降级：该服务器不可用只记日志，不影响其他服务器与应用启动。

## 3. 工具暴露

| 项 | 规则 |
|---|---|
| 前缀 | `MCPToolPrefix = "mcp_"` |
| 名称 | `mcp_{server}_{tool}`，非法字符替换为 `_` |
| 风险级别 | 设为 `network`（外部进程调用，不可假定只读） |
| `Meta.Group` | 设为 `exec`——避免被当作只读而参与并发执行 |
| 远端 schema 非法 | 回退到通用 schema（不因一个坏 schema 阻断注册） |
| 结果截断 | 50k |
| image / resource 块 | 降级为占位说明（当前不渲染 MCP 富媒体） |

## 4. 配置同步

`mcp.json` 是配置**真相源**（DB 同步）。

| 操作 | 行为 |
|---|---|
| `Raw()` | 从 DB 导出成可编辑文本，env 值掩码为 `***` |
| `SaveRaw(content)` | 解析 → 备份 + 原子写文件 → 全量对齐 DB → 热重载子进程；DB 写入失败自动回滚文件 |
| env 加密 | 逐项加密存储；值为 `***` 时保留原密文（掩码回写不覆盖真值） |
| `Add` | 用 `exec.LookPath` 预检命令是否存在 |

设置页直接编辑 `mcp.json` 原文，保存即校验并热重载。

## 5. 生命周期

| 事件 | 处理 |
|---|---|
| 应用启动 | 从 `mcp.json` 同步 DB 并拉起全部启用的服务器 |
| 服务器停用 | 注销其全部工具（`Registry.Unregister`） |
| 子进程死亡 | `Done()` 关闭 → 工具注销（模型不会再调用到死进程） |
| 应用退出 | 关闭全部子进程（避免孤儿进程） |

## 6. 取舍

| 取舍 | 优势 | 代价 |
|---|---|---|
| 独立子进程（stdio） | 崩溃隔离；任意语言实现；协议标准化 | 进程生命周期管理（孤儿回收、PATH 注入）；冷启动慢 |
| 工具以 `mcp_` 前缀暴露 | 与内置工具零冲突，一眼可辨来源 | 名字较长；模型偶尔截断（靠宽松解析兜底） |
| env 加密存储 + 掩码回写 | 密钥不落明文；前端编辑不覆盖原密文 | 依赖主密钥可用（换机或删配置即失效） |
| 指纹增量对齐 | 改一个服务器不影响其他（不重启全部） | 指纹计算需覆盖全部影响启动的字段 |
| 风险级别设为 network + Group=exec | 不误判为只读，不参与并发执行 | 每次都走审批（外部调用不可假定安全） |
| `mcp.json` 为真相源 | 用户可直接编辑、可版本管理 | 需维护文件与 DB 的双向同步与回滚 |
| 富媒体降级为占位 | 不为少数服务器的扩展格式增加渲染复杂度 | 图片类结果当前不可视 |
