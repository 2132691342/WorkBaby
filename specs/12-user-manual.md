# 12 · 用户手册（写给第一次用的人）

## 第一次启动

1. 双击 `WorkBaby.exe`，窗口会自己出现
2. 点右上角 **设置 → 模型服务**，选一个服务商（比如 DeepSeek）
3. 去服务商官网申请一个 API Key，粘贴进去，点 **保存**，再点 **测试**
4. 回到对话界面，直接说人话就行

## 日常使用

| 你想要 | 就这么说 |
|---|---|
| 读文件 | 「帮我看看 D 盘报告文件夹里有什么」 |
| 处理表格 | 「把这个 Excel 按月份汇总，给我个总数」 |
| 写东西 | 「帮我写一封请假邮件，客气一点」 |
| 查资料 | 「搜一下今天的新闻，挑三条讲给我听」 |

- **发送**：回车；换行：Shift + 回车
- 助手干活的每一步（读了哪个文件、跑了什么命令）都会展开成卡片，点开能看细节
- 想中途补充？直接打字发送，它会作为**插话**立刻生效
- 跑偏了？点 **停止**，重新说

## 审批卡

助手要执行有风险的操作（跑命令、改文件）时会先问你：

- **放行**：只这一次
- **本会话内都放行**：同类操作不再问（高风险操作没有这个选项）
- **拒绝**：它不执行，会换个思路

设置里的「执行方式」可以调整这个询问的频繁程度。

## 知识库

设置 → 知识库 → 添加文档（支持 md / txt / pdf / docx / xlsx / html / csv），
可以一次框选多个文件。之后问「根据我给的资料……」它就会去查。

## 技能

内置技能开箱可用。想加自己的：在
`%APPDATA%\WorkBaby\skills\` 下建一个文件夹，放一个 `SKILL.md`，
里面写清楚「什么时候用、怎么做」，重启后自动出现。
也可以在输入框打 `/技能名` 直接让它照着做。

## 常见问题

| 问题 | 解决 |
|---|---|
| 窗口找不到了 | 看右下角托盘，点 WorkBaby 图标 |
| 测试连接失败 | 检查 Key 是否复制完整、接口地址是否正确 |
| 回答到一半停了 | 上游限流或网络抖动，重发一次即可 |
| 想彻底退出 | 托盘右键 → 退出 |
