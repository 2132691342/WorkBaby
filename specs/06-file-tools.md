# 06 · 文件工具与工作区沙箱

## 1. 工作区沙箱

会话可绑定一个本地目录作为工作区；未绑定时用默认工作区 `{home}/workspaces/{sessionID}`。

文件工具的所有路径都相对工作区根解析，越界直接拒绝。

| 输入 | 处理 |
|---|---|
| 相对路径 | 拼到工作区根 |
| 绝对路径 | 必须在工作区根内（`filepath.Rel` 判定，`..` 前缀即越界） |
| 含敏感段 | 拒绝（`.git` / `.env` / `config.yaml` / `/db/`） |

### 为什么限制在沙箱

模型无法越界读写用户其他目录。跨目录任务需先在会话里绑定对应工作区。

### 过程数据目录 `.workbaby/`

绑定工作区时在根下建立沙箱目录，承载与工作区绑定的会话过程数据：

| 子目录 | 用途 |
|---|---|
| `memory/{sessionID}/` | 该会话的长期记忆 |
| `snapshots/{sessionID}/` | 文件写前快照（可回滚） |
| `scripts/` | 本工作区内复用的过程脚本 |
| `output/` | 产出物 |
| `cache/` | 派生缓存（可重建） |
| `tmp/` | 执行期临时文件 |

创建时写入 `.gitignore`（内容 `*`）让整棵沙箱树对 Git 不可见。

**为什么过程数据跟工作区走**：用户清理工作区时一并清掉过程数据是符合直觉的；
系统级数据（配置 / DB / 日志 / 运行时）仍在 `{home}` 下，不进工作区。

### 越界写入告警

写入路径落在工作区根（含其下子目录）但**不在** `.workbaby/` 子树内时，
判定为「污染用户原有目录」并发出 `chat:warn{kind:"file_out_of_sandbox"}`：

| 载荷字段 | 值 |
|---|---|
| `rel_path` / `path` | 相对与绝对路径 |
| `workspace` / `sandbox` | 工作区根与沙箱根 |
| `message` | 「文件写到了工作区 .workbaby/ 之外（污染原有目录）；右键文件变更卡片可一键回滚」 |

不阻塞变更落库（已发生的副作用必须留痕供回滚），但用户必须看见。

## 2. 写前必读

`file_edit` 要求目标文件**在本 run 内先被读过**（`readtrack`）。

读态登记发生在 `file_read` 成功时（`tool.MarkFileRead(ctx, path)`）；
`file_edit` 执行前检查该路径是否在本次 run 的已读集合中，未读则拒绝。

**为什么**：防止模型凭空改写未确认内容。代价是多一次工具往返。

## 3. 变更追踪与回滚

`file_write` / `file_edit` 通过 `Recorder` 接口把变更交给 `FileChangeService`：

| 记录内容 | 说明 |
|---|---|
| 写前快照 | 文件落到 `snapshots/{sessionID}/`，供回滚 |
| diff | unified diff（前端 `DiffView` 渲染，带行号着色） |
| 字节数 / 增删行数 | 列表页统计 |
| `RunID` | 按 run 归属（反幻觉核验的数据源） |

**旁路能力**：写入成功即返回，记录失败或未注入 recorder 都不影响工具语义。

回滚：`POST /chat/changes/:cid/rollback` → 用快照还原文件内容。

## 4. 检索工具

| 工具 | 行为 |
|---|---|
| `file_grep` | 正则内容检索，返回带行号的匹配；**尊重 `.gitignore`**（跳过忽略路径与二进制） |
| `file_glob` | 通配列文件，同样尊重 `.gitignore` |
| `file_list` | 列单层目录（文件名 + 目录标记），支持通配过滤 |

`.gitignore` 解析在 `tool/file/gitignore.go`：读根与各级 `.gitignore`，跳过依赖 / 构建 / 缓存目录。

## 5. 路径解析唯一入口

```go
safePath(workspaceRoot, path) (string, error)
```

三步：绝对化 → `Rel` 判定是否在根内 → 敏感段扫描。

所有文件工具（读 / 写 / 编辑 / 列 / 检索 / 归档）都经它，不各写一份。

## 6. 归档

`archive_manager` 支持 zip 压缩与解压（工作区相对路径）：

| 约束 | 实现 |
|---|---|
| 路径穿越防护 | zip slip 用 `pkg.Within(root, sub)` 校验 |
| 资源限额 | `maxFiles` 与 `maxUncompressedBytes` 双重限制，超限中止 |

## 7. 取舍

| 取舍 | 优势 | 代价 |
|---|---|---|
| 工作区沙箱（文件工具限定根目录） | 模型无法越界读写用户其他目录 | 跨目录任务需先绑定工作区 |
| 写前必读（`file_edit` 要求本 run 读过） | 防止模型凭空改写未确认内容 | 多一次工具往返 |
| 过程数据落 `.workbaby/` | 不污染用户项目结构；清理工作区时一并清掉 | 用户需知道记忆与快照在沙箱内 |
| 敏感段硬拒绝 | 杜绝 `.env` / `.git` / DB 被误改 | 少数合法场景需用户手动处理 |
| 变更追踪为旁路 | 追踪失败不影响写入 | 极端情况下丢失一条可回滚记录（有日志） |
| 检索尊重 `.gitignore` | 结果不被依赖目录淹没 | 用户想检索忽略路径时需显式指定 |
