# 20 · 通用会话历史

## 定位

用户在别处（Claude Code、Codex CLI 等）与 AI 聊过的天，在这里也能看：扫描本机
已知位置的历史文件，解析成统一消息形态，只读浏览、按项目 / 来源 / 日期筛选，
可以把任何一段「搬到 WorkBaby 接着聊」——原项目的上下文不丢。

它不同步、不常驻、不写库：历史是别人家的账，只读翻看；「接着聊」是新建一个
WorkBaby 会话并把原文作为上下文注入，不是把对方的账本搬过来。

## 设计

| 决策 | 选择 | 为什么 | 代价 |
|---|---|---|---|
| 扫描时机 | 进页面按需扫 + 手动刷新 | 不常驻监听；别人的文件随时在变，缓存必然过期 | 每次进页面有一次磁盘扫描（限深限时） |
| 解析器 | 每种来源一个解析器（JSONL / JSON），注册表管理 | 格式各不相同；新来源 = 加一个解析器，不动扫描框架 | 每种来源的字段映射各自维护 |
| v1 覆盖 | Claude Code（`~/.claude/projects/**/*.jsonl`）+ Codex（`~/.codex/sessions/**/*.jsonl`）+ 自定义文件夹（通用 JSONL 兜底） | 这两个是 JSONL 且格式公开可验证；其余（Cursor 的 vscdb、Gemini 私有格式）不猜 | 覆盖不全，界面明说支持哪些 |
| 自定义文件夹 | 用户加路径，按通用 JSONL 解析 | 小众来源格式各异，兜底比不支持好 | 兜底解析质量取决于对方格式规整度 |
| 数据落库 | 不落库 | 翻看不需要持久化；「接着聊」时才生成自己的会话 | 每次扫描重解析（限 500 文件 / 5s） |
| 接着聊 | 新建会话 + 首条上下文注入原文摘要 | 上下文连续；用户在自己的会话里继续 | 注入的是摘要不是原文全文（超长截断） |

### 统一消息形态

```
HistoryEntry{ id, source, project, title, started_at, message_count, messages[] }
HistoryMessage{ role, text, tool_calls?, created_at }
```

`role` 归一到 `user / assistant / tool`；各来源的特有字段（thinking、usage）
保留在 `extra` 里不丢，但界面不展示——只读翻看要的是「当时聊了什么」。

## 契约

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/v1/history/entries?source=&q=` | 扫描结果（项目 / 标题 / 时间 / 条数） |
| GET | `/api/v1/history/entries/:id` | 一段会话的完整消息（只读） |
| POST | `/api/v1/history/folders` | 注册自定义文件夹 `{path}` |
| POST | `/api/v1/history/folders/delete` | 删除注册 |
| GET | `/api/v1/history/folders` | 已注册文件夹 |
| POST | `/api/v1/history/continue` | 接着聊 `{entry_id}` → 新建 WorkBaby 会话 |

错误码：`9301` 历史会话不存在（扫描结果已过期）；`9302` 自定义文件夹不存在；
`9303` 解析失败（文件损坏 / 格式不识别，跳过该文件并在结果里计数）；
`9304` 扫描超时（结果可能不全，明说）。

## 关键流程

1. 进指挥台历史页 → 并发扫各来源根目录（限时 5s / 500 文件）→ 列表（项目 / 来源 / 时间）
2. 点一段 → 右栏只读渲染（用户 / 助手气泡，工具调用折叠展示）
3. 「接着聊」→ 弹一个小框让用户补一句「接下来想干嘛」→ 建会话 + 注入上下文 →
   跳转到对话页，输入框里留着用户补的那句
4. 注册自定义文件夹 → 下一次扫描带上它

## 不变量

| 不变量 | 锁死原因 |
|---|---|
| 只读：不写、不改、不删任何历史文件 | 别人的账本动不得；出任何问题都说不清 |
| 扫描有硬上限（文件数 / 深度 / 时长） | 大户的 projects 目录有几千个文件，全量解析会把页面挂死 |
| 解析失败跳过并计数，不让整页失败 | 一个坏文件不该让整个历史页报错 |
| 注入上下文注明来源与时间 | 「这段是 9 月 12 日在 Claude Code 里聊的」——不注明就是幻觉温床 |
| 不缓存跨请求 | 对方的文件在变；缓存 = 展示过期内容 |

## 取舍

- **不落库**：省一张表与一套同步逻辑；代价是每次进页面都要扫（有上限兜底，
  千文件内百毫秒级）。
- **兜底解析而非逐家精装**：部分来源的格式非公开且会变，精装一个坏一个；
  兜底 + 自定义文件夹把「不支持的格式」交还给用户自己。
- **摘要是截断不是全文**：注入全文会把窗口一次吃光；原文随时能在原文件里看，
  这里只负责「让我知道聊过什么并能接上」。
