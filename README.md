# WorkBaby

Windows 单机 AI 工作台：一个把智能体引擎装进 GUI 的桌面应用。

智能体循环、模型协议适配、工具执行、会话落盘全部由本进程内的 Go 代码实现。
配好一个服务商的 API Key 就能开始干活——不需要装引擎、不需要装 node、
不需要插件生态。用户机器上已有的工具链（git / node / python）按需探测、直接调用。

## 定位

WorkBaby 面向「日常要在自己电脑上让 AI 干活」的办公人员。命令行 AI 助手的门槛
不在模型能力，而在**操作**：模型怎么配、工具装没装、当前跑到哪一步、哪一步失败了，
全靠改 JSON 和记命令，看不清状态。

WorkBaby 把这些收进一个界面：

| 域 | 能做什么 |
|---|---|
| 对话 | 流式输出、思考折叠、工具卡片（含差异视图）、插话 / 排队 / 停止、上下文水位、待办面板、结构化提问卡 |
| 模型 | 服务商与模型的增删改查、连通性探测、密钥恒为掩码 |
| 技能 | 10 个推荐技能一键装齐，可开关 / 编辑 / 重置 / 新建 / 导入 / 删除 |
| 工作区 | 文件树与预览、git 状态 / 差异 / 历史 / 分支 / 提交 / stash / 推拉 |
| 联网 | 联网搜索、网页抓取（HTML / PDF / JSON）、内网地址拦截 |
| 代码 | 工作区预索引：文件与符号的毫秒级检索 |
| MCP | stdio / HTTP 服务增删改查与开关，一条「测试连接」完成 MCP 握手 |
| 会话 | 列表、改名、删除、隐藏单轮、导出 HTML |

## 设计要点

**引擎在进程内。** 没有子进程要拉起、没有握手协议、没有崩溃重启、没有版本探测。
`backend/agent/` 是一个纯 Go 包，只依赖标准库与 `pkg`，不知道 HTTP、界面与上层编排存在。

**会话文件是唯一真相。** 每一次对话都追加进 `data\sessions\<工作区编码>\SES_xxx.jsonl`，
界面状态重启后由回放重建。会话头只在创建时写一次，之后永不重写——断电也不会写坏唯一真相。

**工具集是能力的唯一边界。** 模型能做什么，取决于工具注册表里注册了什么。
系统提示里的工具清单直接从注册表读，两者绝不会不一致。

**计划模式是引擎级闸门。** 只读态挂在注册表上，一次实现管住全部写工具。
判定规则「未登记按写处理」：漏登记一个写工具，计划模式就名存实亡；
而漏登记一个读工具只会让模型多问一句——两者不对等。

**一份真相，一个写入口。** 服务商与模型在 SQLite，服务商凭据与模型清单同表管理；
设置与技能开关台账在 `workbaby.json`；会话在 JSONL；技能在目录位置；MCP 在 `mcp.json`。
没有第二份注册表。

**路径有边界。** 工具与文件接口一律校验路径落在允许的根目录内——
模型给的路径来自对话内容，不能成为逃出工作区的通道。

## 目录

```
%LOCALAPPDATA%\WorkBaby\          （开发态加 -dev 后缀）
├── workbaby.json                 # 设置与技能开关台账
├── workbaby.db                   # SQLite：服务商 / 模型 / 检索索引 / 用量
├── logs\                         # 按天滚动
├── webview\                      # WebView2 用户数据
├── cache\                        # 壳自己的缓存
├── sessions\                     # 会话 JSONL（唯一持久真相）
└── skills\ skills_disabled\      # 技能启用 / 停用区
```

安装态是**一个目录**：exe + `assets\skills\`（推荐技能包），
前端产物经 `go:embed` 编进 exe，不额外分发静态文件。
运行时不随包发：git / node / python 全部用系统已装的。
卸载程序会先问一句**是否连数据目录一起删**，默认保留。

## 技术栈

| 层 | 选型 |
|---|---|
| 桌面壳 | Wails v3（无边框窗口，前端自绘标题栏，WebView2） |
| 语言 | Go 1.26（无 cgo） |
| 业务服务 | gin（业务 API + SSE 全走 HTTP，127.0.0.1 随机端口） |
| 持久化 | 设置台账用标准库 JSON 文件（原子整写 + 互斥锁），派生数据用 SQLite（纯 Go 驱动） |
| 索引 | 内存倒排 + SQLite 持久化，支持 frecency 排序 |
| ID | ULID，带业务前缀（`RUN` / `ASK` / `EVT` / `JOB` / `SES`） |
| 模型协议 | OpenAI 兼容 `/chat/completions` 流式 |
| 前端 | Vue 3 + TypeScript + Vite + Element Plus + Pinia + UnoCSS |

## 开发

```bash
go build ./...                                        # 全包可编译
go vet ./...                                          # 静态检查
cd frontend && npx vue-tsc --noEmit -p tsconfig.json  # 前端类型检查
go test ./tests -count=1                              # 场景测试
```

`task check` 一条命令跑完格式、静态检查与测试。
`task build` 产出 `bin\WorkBaby.exe`，`task package` 出 NSIS 安装包。

工程规范见 `AGENTS.md`，架构与模块见 `docs/`。
