# 文件与工作区

WorkBaby 干活的落点是**工作区**：会话绑定一个本地目录后，文件读写、过程数据、变更回滚都围绕它展开。

## 1. 绑定工作区

- 入口：会话标题栏的「工作区」chip（或聊天输入区），选择一个本地目录（绝对路径）
- 绑定后：文件工具的根 = 该目录；记忆、快照、脚本等过程数据也放在它下面

## 2. 工作区沙箱（.workbaby/）

绑定后 WorkBaby 会在目录下建一个 `.workbaby/` 沙箱，承载全部过程数据：

| 子目录 | 内容 |
|---|---|
| `memory/` | 该会话的长期记忆 |
| `snapshots/` | 文件写前快照（供回滚） |
| `scripts/` | 技能脚本 |
| `output/` `cache/` `tmp/` | 产出与临时文件 |

沙箱整棵树已写入 `.gitignore`（内容 `*`），对 Git 完全不可见，不会污染你的仓库。**整个目录删掉即可彻底清理，不影响真实文件。**

## 3. 文件面板

聊天页右侧栏提供：

- **文件树**：浏览工作区目录结构（未绑定时回退到受管文件夹树）
- **变更与产物**：本会话产生的所有文件变更，unified diff 逐行着色展示

## 4. 变更追踪与回滚

AI 每次写文件都会留痕：

| 机制 | 说明 |
|---|---|
| 写前快照 | 修改前的内容存入沙箱，随时可还原 |
| diff 展示 | 变更卡片显示前后差异（行号 + 增删着色） |
| 一键回滚 | 变更卡片上回滚，文件恢复到修改前 |

> 如果发现文件被写到了沙箱之外（污染了原有目录），系统会明确告警，变更卡片仍可一键回滚。

## 5. 目录信任

对工作区之外的目录，首次写入前会先询问（fail-closed）：登记信任后后续写入不再打扰；祖先目录的信任可被子目录继承。「设置 → 安全与高级」可查看与撤销已信任目录。
