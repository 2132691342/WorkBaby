# 聊天与采样参数

WorkBaby 的聊天输入框支持逐条消息的采样控制，让你对生成效果有精细掌控。

## 思考强度（thinkingEffort）

控制模型是否输出推理过程，以及推理的深浅：

| 档位 | 含义 |
|---|---|
| `off` | 关闭思考，只输出最终回答（更快、更省 token） |
| `low` | 浅层思考 |
| `medium` | 默认，平衡推理深度与速度 |
| `high` | 深度思考，适合复杂推理任务 |

思考文本与正文严格分离：思考只进 `thinking` 字段，正文进 `content`，互不污染。

## 温度（temperature）

取值范围 `0.0 ~ 2.0`，控制采样的随机性：

- **0.0**：确定性最强，适合代码 / 事实问答
- **0.7 左右**：创意写作常用
- **留空**：走 Provider 级默认值，再缺省走全局默认（0.2）

## 参数优先级

请求级采样 > Provider 级默认 > 全局默认。在输入框的「采样参数」chip 里调整，浏览器本地记忆，下次打开仍在。

## 工具执行权限

输入框顶部的权限 chip 或 `/trust` 命令在四档间循环（顺序：计划 → 需确认 → 自动 → 完全访问）：

- **计划（restricted）**：只读检查代码，写文件 / 执行命令一律拒绝（不弹审批，模型可见拒绝原因自行改道）；适合先看再动手
- **需确认（confirm）**：只读直接执行；写文件、执行命令、删除等需逐条确认
- **自动（auto）**：读文件与编辑文件直接执行；执行命令、删除、联网仍需确认
- **完全访问（full）**：全部放行，包括命令执行与删除，仅在完全可信的批量任务中使用

不可逆操作（如 `rm -rf`、格式化磁盘）无论何种档位都会强制弹红色审批卡。
