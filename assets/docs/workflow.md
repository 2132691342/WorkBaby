# 工作流

工作流是可视化拖拽的 DAG 编排，把 LLM、工具、条件分支、HTTP 请求等节点串成自动化流程。

## 节点类型

| 节点 | 作用 |
|---|---|
| LLM | 调用模型生成 / 推理（选 Provider + 模型，支持系统/用户提示词模板） |
| Tool | 执行内置工具（exec / file / websearch 等） |
| Code | 代码执行（预留，当前版本占位） |
| Condition | 表达式条件分支（expr-lang），输出 true/false 两路 |
| HTTP | 发起 HTTP 请求（仅 GET / POST） |
| Human Input | 暂停等待人工输入 |
| Channel | 通过通知通道发送消息 |

## 编辑

「工作流」页新建 → 进入画布 → 左侧调色板点击添加节点 → 连线 → 点击节点在右侧属性面板按表单配置 → 点「保存到后端」。拖拽后的布局、连线分支与「图输出」映射都会随保存持久化。

**分支**：从条件节点右侧的 `T` / `F` 出口分别连线，只有命中的那一路下游节点会执行。

## 运行

- 手动触发：工作流列表点「运行」
- 定时触发：绑定「定时任务」，用 cron 表达式周期执行
- 执行记录：可查看每次运行的状态、输入输出、节点级明细
- 运行中画布上的节点会高亮当前状态（执行中 / 成功 / 失败 / 跳过）

## 安全

HTTP 节点仅允许 `GET` / `POST`，防止配置破坏性操作。Human Input 节点会暂停执行，等待用户在界面上回填后再继续。
