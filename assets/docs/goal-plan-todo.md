# 目标模式 · 计划模式 · 待办

三种「任务推进」机制，分别解决：长任务怎么自动跑完（目标）、动手前怎么先看清楚（计划）、多步骤怎么不丢项（待办）。

## 1. 目标模式

设定目标后，每轮对话结束时系统会用一次独立的轻量模型调用**按实据校验**是否达成；未达成则自动续跑下一轮，直到达成或到达轮数上限。

| 操作 | 说明 |
|---|---|
| 设定 | 会话「目标」入口填写目标文本（越具体、越可校验越好） |
| 暂停 / 恢复 | 已完成的轮次与产物都保留；`done` 状态需设新目标 |
| 清除 | 解除目标 |

### 校验只看实据

- 声称「已创建文件」→ 必须真的存在且内容匹配
- 声称「已跑通」→ 命令必须真的退出码为 0 且输出对得上
- 「我已完成」「应该没问题」这类口头结论**不算达成**

### 自动暂停的情况

run 失败 / 被取消 / 校验调用失败 / 达到轮数上限（默认 20 轮）——异常状态一律暂停，不会盲目续跑烧 token。确认进度后可手动恢复继续。

> 目标校验本身是一次模型调用（有用量）；`chat:done` 之后界面会保持连接，等校验结束无缝续看新的一轮。

## 2. 计划模式

权限下拉切到「计划」：进入**只读探索阶段**。

- 写文件、执行命令等改动型工具被硬拦，模型只能读代码、查资料、给方案
- 方案确认后切回「需确认」（或更高档）开始动手；从计划模式退出需要审批

适合：不熟悉的大型改动、想让 AI 先出实施计划再拍板的场景。

## 3. 待办（todo）

多步骤任务中模型会维护一张会话待办清单（`todo` 工具）：

- 清单实时展示在聊天区，勾选项自动打勾
- 你也可以直接勾选 / 取消勾选
- 长任务中断后，待办清单还在，续跑时模型接着推进

## 4. 怎么选

| 场景 | 用什么 |
|---|---|
| 「把这个功能完整做完」一类大目标 | 目标模式 |
| 「先看看代码再改」 | 计划模式 |
| 步骤多、怕漏项 | 待办清单（模型自动维护） |
| 不想占着对话窗口 | 后台任务（见「仪表盘 · 运行历史 · 后台任务」篇） |
