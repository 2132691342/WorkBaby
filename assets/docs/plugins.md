# 插件

插件给助手加**新动作**：新的工具、新的斜杠命令、或者说改掉它的一些默认习惯。
技能教它「怎么做一件事」，插件则是给它「多一只手」。

## 装别人的插件

在设置 → 插件里有两条路：

| 方式 | 什么时候用 |
|---|---|
| 装插件包 | 别人发布了 npm 包或 git 仓库。填来源，例如 `npm:@scope/pi-tools`、`git:github.com/owner/repo`，点「装上」 |
| 导入插件文件 | 你手上直接有一个 `.ts` / `.js` 文件或一个目录 |

装上以后不需要重启应用：程序会自动让助手引擎重读一遍。

装的时候下面的框里会一行行打印过程。如果停在某个地方不动，把那几行连同来源一起发给
给你插件的人——通常是他那边缺了什么依赖。

## 停用与删除

每一行右边有一个开关：

- **关掉**：助手从此看不到它，文件还在，随时可以再打开
- **删除**：文件也一并删掉。误点了不要紧，第一次点只是变红，再点一次才真的删

自带的那一条（`workbaby.ts`）没有开关，也删不掉。它是「动手前问你一句」的实现，
停掉它你就再也看不到审批提示了。

## 和技能、MCP 的区别

| 名字 | 它是什么 | 你什么时候会用 |
|---|---|---|
| 技能 | 一段文字写成的方法：什么时候做、按什么步骤做 | 你有一套固定做法想让它照做 |
| 插件 | 一段代码，给助手加新动作或改行为 | 你想要一个它在当前版本里没有的能力 |
| MCP | 另一个程序暴露出来的工具，由助手连过去用 | 你已经有一个能查东西的程序（数据库、内部服务） |

三者都在设置页里管，但改的东西不同：技能改文字，插件改能力，MCP 改连接。

## 装之前想一想

插件能在你的电脑上执行代码，用的是你自己的权限。所以：

- 只装你信得过来源的插件
- 装完先看一眼设置 → 工具里多了什么，再决定要不要一直开着
- 拿不准就先关着，需要的时候再打开

## 助手引擎自己的斜杠命令

插件可以注册 `/某个命令`。这类命令会出现在输入框的 `/` 菜单里，右边标着「引擎」。
选它之后，剩下的说明交给你补；发出去由引擎自己展开。

插件装的提示模板（prompt template）也走这条路，标「引擎 · 模板」。
