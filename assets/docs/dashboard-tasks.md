# 仪表盘 · 运行历史 · 后台任务

这一组页面回答三个问题：**花了多少（用量）、跑过什么（历史）、怎么并行干活（后台任务）**。

## 1. 仪表盘

「设置 → 仪表盘」展示：

| 卡片 | 内容 |
|---|---|
| 缓存命中率 | 区间内 prompt 缓存命中占比（命中部分按缓存价计费，省钱看得见） |
| 缓存读 / 计费 / 输出 | token 三项汇总（1024 进制人类可读） |
| 费用 | 区间费用估算（USD；未配置单价的模型不计入） |
| 最近活动 | 最新对话消息流 |
| 快捷入口 | 新建会话 / 导入文档 / 记忆中心 |

token 趋势支持今日（24 小时桶）/ 本周 / 本月 / 自定义区间，输入、输出、缓存读三条线分开看。

## 2. 运行历史

「设置 → 运行历史」列出历次 run（哪次对话、几点、结果如何）。点进某次运行可查看完整的事件明细，排查「AI 当时到底做了什么」。

## 3. 后台任务

长任务不想占着对话？提交为后台任务，**提交即返回，跑完出结果**：

| 维度 | 说明 |
|---|---|
| 提交 | 右栏「后台任务」面板：挂在一个会话上（工作区与模型取自它），填提示词提交 |
| 执行 | 队列容量 64，2 个 worker 并发；与前台对话完全并行 |
| 状态机 | `pending → running → completed / failed / cancelled` |
| 取消 | 随时取消（幂等）；已产生的文件变更仍可回滚 |
| 重启 | 应用重启后未完成任务标记为失败（需重新提交） |

### 审批注意

后台任务**不会弹审批窗**（无人值守场景不能挂起等一个不会到来的决策）：它只吃「免审授权」。需要写文件 / 执行命令的任务，请先在对应会话里批一次「本会话允许」，再提交后台。

### 与前台对话的分工

| | 前台对话 | 后台任务 |
|---|---|---|
| 审批 | 弹卡片等你决策 | 只吃免审授权 |
| 结果 | 落为对话消息 | 落为任务记录（结果 / 错误字段） |
| 用量 | 归因到对话 | 归因到任务（成本单独看） |
