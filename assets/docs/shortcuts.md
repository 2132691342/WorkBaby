# 快捷键与命令速查

WorkBaby 支持纯键盘操作与斜杠命令，熟悉后可以明显加快日常使用。本文是速查表，记不住时也可在输入框输入 `/help` 查看面板中的完整说明。

## 全局快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+N` | 新建会话（保留当前会话，直接跳到新会话） |
| `Ctrl+K` | 打开命令面板（导航 / 动作 / 会话切换 / 权限模式 / 工具启停） |
| `Ctrl+Shift+P` | 打开命令面板（与 `Ctrl+K` 相同） |
| `Ctrl+/` | 聚焦输入框 |
| `Ctrl+B` | 折叠 / 展开左侧导航栏 |
| `Ctrl+Shift+F` | 切换焦点模式（隐藏思考与工具时间线，只看正文） |

> 提示：在输入框、搜索框等可编辑控件中，除 `Esc` 外全局快捷键不会触发，避免误打断正在输入的内容。

## 输入框内快捷键

| 按键 | 作用 |
|---|---|
| `Enter` | 发送消息 |
| `Shift+Enter` | 换行 |
| `Esc` | 关闭当前弹层 / 取消操作 |

## 常用斜杠命令

在聊天输入框输入 `/` 即可呼出命令面板（支持模糊匹配）。命令按执行位置分两类：带「本地」标签的在前端直接执行（如切模型 / 导出），其余跳转到对应后端接口。

| 命令 | 作用 |
| --- | --- |
| `/new` | 新建会话 |
| `/rename <新标题>` | 重命名当前会话 |
| `/clear` | 清空当前会话消息 |
| `/fork [消息ID]` | 从指定消息分叉新会话（不传则从末尾分叉） |
| `/truncate <消息ID>` | 截断会话到指定消息 |
| `/compact [保留指示]` | 压缩历史上下文；可附带压缩后必须保留的要点 |
| `/context` | 查看当前上下文占用分段（system / 历史 / 工具） |
| `/resume <会话ID\|关键词>` | 跨会话快速恢复（关键词搜标题 / 内容） |
| `/goal [<目标描述>\|pause\|resume\|clear]` | 查看 / 设定 / 暂停 / 恢复 / 清除当前会话目标 |
| `/model <模型名>` | 切换当前会话模型 |
| `/agent <default\|coding\|research\|writer>` | 切换当前 Agent（工具集与记忆策略随之切换） |
| `/trust` | 循环切换执行模式（计划 / 需确认 / 自动 / 完全访问） |
| `/tasks` | 打开后台任务中心 |
| `/export` | 导出当前会话为 Markdown |
| `/help` | 查看全部命令说明 |

## 常用操作入口

| 操作 | 路径 |
|---|---|
| 配置模型 | 左侧「设置」→「模型」 |
| 上传知识库 | 左侧「知识库」→「导入文件」 |
| 绑定工作区 | 聊天输入框上方工作区 chip（或「设置」→「工作区」） |
| 查看后台任务 | 聊天页右侧「任务中心」，或 `/tasks` |
| 命令面板 | `Ctrl+K`（导航、切会话、启停工具都在这里） |
