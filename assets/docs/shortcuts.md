# 快捷键与命令速查

WorkBaby 支持纯键盘操作与斜杠命令，熟悉后可以明显加快日常使用。本文是速查表，记不住时也可在输入框输入 `/help` 查看面板中的完整说明。

## 全局快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl+N` | 新建会话（保留当前会话，直接跳到新会话） |
| `Ctrl+K` | 打开命令面板（导航 / 动作 / 会话切换 / 权限模式 / 工具启停） |
| `Ctrl+Shift+P` | 打开命令面板（与 `Ctrl+K` 相同） |
| `Ctrl+/` | 聚焦输入框 |
| `Ctrl+B` | 折叠 / 展开左侧导航栏 |
| `Ctrl+Shift+F` | 切换焦点模式（隐藏思考与工具时间线，只看正文） |

> 提示：在输入框、搜索框等可编辑控件中，除 `Esc` 外全局快捷键不会触发，避免误打断正在输入的内容。

## 输入框内快捷键

| 按键 | 作用 |
|---|---|
| `Enter` | 发送消息 |
| `Shift+Enter` | 换行 |
| `Esc` | 关闭当前弹层 / 取消操作 |

## 常用斜杠命令

在聊天输入框输入 `/` 即可呼出命令面板（支持模糊匹配）。命令分为三类：右侧带「后端」标签的命令有后端逻辑，带「本地」标签的在客户端直接执行。

| 命令 | 作用 |
|---|---|
| `/help` | 查看全部命令说明 |
| `/new` | 新建会话 |
| `/clear` | 清空当前会话消息 |
| `/compact [保留指示]` | 压缩历史上下文；可附带压缩后必须保留的要点 |
| `/export` | 导出当前会话为 Markdown |
| `/model <模型名>` | 切换当前会话模型 |
| `/agent <default\|coding\|research\|writer>` | 切换当前 Agent |
| `/trust <default\|auto-edit\|yolo>` | 切换工具权限模式 |
| `/tasks` | 打开后台任务中心 |
| `/focus` | 切换焦点模式 |
| `/regenerate` | 重新生成上一条回复 |
| `/attach` | 添加附件 |
| `/workspace` | 切换当前工作区目录 |
| `/theme` | 打开外观设置 |

## 常用操作入口

| 操作 | 路径 |
|---|---|
| 配置模型 | 左侧「设置」→「模型」 |
| 上传知识库 | 左侧「知识库」→「导入文件」 |
| 绑定工作区 | 聊天输入框上方工作区 chip，或 `/workspace` |
| 查看后台任务 | 聊天页右侧「任务中心」，或 `/tasks` |
| 命令面板 | `Ctrl+K`（导航、切会话、启停工具都在这里） |
