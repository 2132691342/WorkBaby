# 知识库与 RAG

知识库让 AI 能基于你的私有文档作答，避免幻觉。

## 添加文档

「知识库」页上传支持 PDF / Word / Markdown / 纯文本。上传后自动解析 → 切分 → 建立 FTS5 全文索引。

## 检索原理

- **切分**：按语义块切分，控制块大小与重叠
- **索引**：SQLite FTS5（trigram + BM25），中文友好
- **检索**：用户提问时召回最相关片段，与问题一起送入模型生成

## 聊天中引用知识库

聊天时用 `@` 唤起 mention，选择知识库文档即可让 AI 参考对应资料。

## 维护

- 文档可重新索引（内容变化后）
- 索引失败会有明确状态标记，可重试
- 删除文档会级联清理分块与索引
