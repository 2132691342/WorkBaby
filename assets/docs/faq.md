# 常见问题

## 对话相关

**问：发送后一直转圈，没有回答？**
先看输入框上方有没有审批卡片在等你点「放行」——助手可能在等你拍板。
如果没有，检查顶栏的连接状态灯是不是黄色（断线自动重连，等几秒）。

**问：回答写到一半停了？**
看到「回答被截断」的提示就点 **继续**，助手会接着写。
频繁截断说明选的模型输出上限小，换个模型更好。

**问：想让它重新回答？**
出错提示旁边有 **重试**；也可以把不满意的那条重新说一遍。

**问：对话太多找不到了？**
左栏列表按「今天 / 本周 / 更早」分组，超过一屏点底部「加载更早的对话」。

## 使用相关

**问：它会偷偷改我的文件吗？**
默认不会。每次改文件、跑命令前都要你点「放行」。拒绝永远安全。
如果你希望少被打断，设置 → 行为 → 执行方式 可以调整。

**问：能处理 Excel / Word / PDF 吗？**
能。输入框里打 `@` 弹出文件面板，选中文件发送即可（也可以直接把路径打在消息里）。
常用资料放进知识库（设置 → 知识库）可以长期复用，问答时自动去查。

**问：上下文用了多少在哪看？**
输入框左边有一个水位环，鼠标悬上去会显示具体数字。
接近满了它会自动整理较早的对话内容，你无感。

## 软件相关

**问：关掉窗口程序还在？**
默认收进右下角托盘。想彻底退出：托盘图标右键 → 退出；
也可以在设置 → 行为 里关掉「关闭时收进托盘」。

**问：开机自动启动怎么关？**
设置 → 行为 → 取消勾选「开机自动启动」。

**问：数据备份？**
全部数据在 `%APPDATA%\WorkBaby\` 一个文件夹里，复制走就是完整备份。

**问：想看看它每步做了什么？**
对话里的工具卡片点开就是完整细节（参数、输出、耗时）；
每个回答下面还标了这轮花了多少 token。
