# 常见问题

## 对话相关

**问：发送后一直转圈，没有回复？**
先看输入框上方有没有审批卡片在等你点「放行 / 拒绝」——助手可能正在等你批准。
如果没有，检查标题栏的连接状态，或者是不是在重组（断线自动重连，等几秒）。

**问：回复写到一半停了？**
看到「回复被中断」的提示就点 **继续**，助手会接着写。
频繁中断说明选的模型输出上限太小，换个模型更好。

**问：想让它重新回答？**
出错提示边上有 **重试**；也可以把不满意的那段重新说一遍。

**问：对话太多找不到了？**
左栏列表按「今天 / 本周 / 更早」分组，超过一屏点底部「加载更早的对话」。

## 使用相关

**问：它会乱动我的文件吗？**
默认不会。每次改文件、跑命令前都要你点「放行」。
如果你希望少被打断，**设置 → 行为 → 执行方式** 可以调整。

**问：能处理 Excel / Word / PDF 吗？**
能。输入框里打 `@` 弹出文件面板，选中文件发送即可（也可以直接把路径打在消息里）。
常用资料建议放进知识库（**设置 → 知识库**），可以长期复用，问答时它自己会去检索。

**问：上下文用了多少在哪看？**
输入框左边有一个水位环，鼠标悬停会显示具体数字。
快满了它会自动整理更早的对话内容，你无感。

**问：它跑的脚本报错说找不到 python / node？**
不用装：Python 与 Node 运行时已经打包在程序里，助手优先用内置那份。
想确认状态，去 **设置 → 关于** 看运行时一栏。

**问：我电脑上本来装过助手引擎（PI），会被覆盖吗？**
不会。启动时会先找系统里那一份，找到了就直接复用你的版本与配置。
只有找不到时才会用程序内置的那份。你原来在命令行里配的模型服务同样认。

**问：内置运行时会占多少空间？**
Node 与 Python 两份归档合计约 47MB，打进 exe；
首次启动解压到本机数据目录，之后不再解压。卸载时可以选择一并删除。

## 软件相关

**问：关掉窗口程序还在？**
默认收进右下角托盘。想彻底退出：托盘图标右键 → 退出；
也可以在 **设置 → 行为** 里关掉「关闭时收进托盘」。

**问：怎么开机自启？**
**设置 → 行为** → 勾选「开机自启动」。

**问：数据存在哪？**
全部数据在 `%APPDATA%\WorkBaby\` 一个文件夹里，备份走它就是完整备份。

**问：想看它每一步具体做了什么？**
对话里的工具卡片点开就是完整细节（参数、输出、耗时）；
每个回复下面还标了这一轮花了多少 token。
更细的按次运行记录在 **指挥台 → 运行**。

**问：反应变慢了？**
先看 **仪表盘** 里平均耗时有没有变长；某个特别慢的轮次，
去 **指挥台 → 运行** 点开那一条，时间线会指出慢在哪一步（等模型还是跑工具）。
