# 常见问题

## 启动后提示「还没有可用的模型配置」

去 **模型**（左侧一级导航） 添加至少一个服务商和模型，并填好 API key。设置默认模型后对话页即可使用。

## 对话页一直转圈

看右上角状态条：如果是模型流中断，内核会自动重试（最多 3 次）；点「停止」可中断重试等待。

## 助手改错了文件怎么办

工作区页可以逐文件丢弃工作区改动（未跟踪文件会被删除）；已提交的历史用 git 回退。

## 技能是什么

技能是一段按需注入的说明书（SKILL.md）：告诉助手某类任务怎么做。内置技能随应用分发，你也可以在设置里新建或导入；停用的技能不进提示词。

## MCP 服务连不上

在 **MCP**（左侧一级导航） 检查配置原文是否合法、命令是否存在；stdio 服务启动超时默认 10 秒。断线不自动重连，点「重新连接」或重开会话即可。

## token 用量在哪看

仪表盘按天与按模型聚合；单条消息的读数在消息详情里。usage 一律以服务端返回为准。
