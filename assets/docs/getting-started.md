# 快速上手

WorkBaby 是 **PI** 的桌面外壳。它不自己实现 AI，只做四件事：启动 PI、把它的输出显示成界面、把它的配置摊开给你改、在它缺东西时帮你装上。

这台机器上的 `pi` 命令与 WorkBaby 共用同一份配置（`~/.pi/agent`），所以你以前装过的技能、插件、模型、MCP 服务，打开就在。

## 第一次打开

1. **环境自检**：向导会依次检查 Node、PI、模型三项，卡在哪一步就直接落在那一步。
2. **装 PI**（如果还没有）：点一次「安装」，进度会实时打印出来。装的是官方 `@earendil-works/pi-coding-agent`。
3. **配模型**：填一个 OpenAI 兼容的接口地址与密钥即可。保存后写进 PI 的 `models.json`，命令行也立刻能用。

三项都通过就进对话页。

## 问一句话

- 在底部输入框里用大白话写需求，回车发送。
- 需要它看某个文件，输入 `@` 选文件；需要某个技能，输入 `/` 挑命令或技能。
- 回复过程中可以 **插话**（发送键变成「插话」）：助手会在当前这轮工具跑完后读你的新要求。
- `Esc` 停止当前这一轮。

## 它是真的会动手

助手能读文件、改文件、跑命令——这些工具都在 PI 里，不是你装的另一个程序。

- 每一步都会在对话里显示成一张可展开的工具卡：干了什么、参数、输出、耗时。
- 有些插件会先问你一句（比如写入前确认），问题会以卡片形式出现在对话末尾。
- 改动本身可以在「工作区」页对账，并在那里收成一次提交。

## 换模型 / 换思考档

输入框下方两枚开关：

- **模型**：左列服务商、右列模型，点一下就写回这条对话。任意旧对话都能换成任意服务商的任意模型。
- **思考档**：从「不思考」到「最多」。深度越深越慢越贵。

## 找不到东西时

| 你想找 | 去哪 |
|---|---|
| 我的技能 | 设置 · 技能 |
| 我装的插件 / 包 | 设置 · 插件 |
| 模型服务 | 设置 · 模型服务 |
| 助手能用的工具 | 设置 · 工具 |
| MCP 外部工具 | 设置 · MCP |
| 配置文件到底在哪 | 设置 · 行为（页底列出全部路径） |
| 花了多少钱 | 仪表盘 |
