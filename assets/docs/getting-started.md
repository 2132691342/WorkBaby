# 快速上手

## 它是什么

WorkBaby 是一个桌面里的个人 AI 工作台：你说人话，它去读文件、跑脚本、查资料、写文档。
内核是外部的一个成熟 Agent，WorkBaby 负责把它跑起来，并且让你看见并控制它怎么跑——
每一步花了多少、改了哪个文件、从哪一步能重来。

数据全在本机：会话内容与用量记录都存在你自己电脑上，密钥加密保存。

## 第一次启动

1. 双击 WorkBaby.exe，窗口会自己出现
2. 首次会做一次环境检查：Node 与助手引擎已经打包在程序里，第一次启动自动解压，要等几秒；
   如果你电脑上本来装过助手引擎，会直接复用你那一份
3. 点左侧导航栏的 **设置** 图标 → **模型服务**，选一个你常用的服务商模板（也可以自己填接口地址）
4. 去服务商官网申请一个 API Key，粘贴进去，点 **拉取模型列表**，勾一个模型，**保存**，再点 **测试**
5. 点导航栏的 **对话** 图标回到聊天界面，直接说人话就行

> 欢迎页会依次检查「运行时 → 助手引擎 → 模型服务」三项，缺哪项就给你一个直达对应设置的按钮，
> 不会让你对着一个不能用的输入框打字。

## 日常使用
| 你想要 | 就这么说 |
|---|---|
| 读文件 | 「帮我看看桌面上那个报告文件夹里有什么」 |
| 处理表格 | 「把这个 Excel 按月份汇总，给我个总数」 |
| 写东西 | 「帮我写一封请假邮件，客气一点」 |
| 查资料 | 「搜一下今天的新闻，挑三条讲给我听」 |

- **发送**：回车；换行：Shift + 回车（可在 **设置 → 行为** 里改成 Ctrl + 回车 发送）
- 助手干活的每一步（读了哪个文件、跑了什么命令）都会展开成卡片，点开能看细节
- 想中途补充？直接打字发送，它会作为**插话**立刻生效
- 跑偏了？点 **停止**，重新说
- 上游服务队在繁忙时它会自动重试，提示条上有一个「停止重试」，不想等就点它
- 想把整段对话存下来？左侧会话列表悬停时点下载图标，存成一份 HTML，双击就能看

## 看它花了多少、从哪重来

| 你想知道 | 去哪看 |
|---|---|
| 这段时间一共用了多少 token、缓存命中率如何 | **仪表盘**：四个计数卡 + 一张趋势图 |
| 哪一轮花了最多、哪个工具最慢 | **指挥台 → 运行**：每次运行一行，点开是时间线 |
| 上一轮改错了，想从某个步骤重来 | **指挥台 → 运行** 里那次运行的「从这一轮重开」 |
| 这次和上次比是好是坏 | **指挥台 → 评估**：把满意的存成基线，之后自动对比 |

每一轮对话结束，用量自动记一行；对话里每条回复下面也会标出这一轮花了多少。

## 界面一览

| 位置 | 是什么 |
|---|---|
| 左侧导航栏 | 六个入口：对话 / 工作区 / 指挥台 / 仪表盘 / 帮助 / 设置；最下面是明暗主题切换 |
| 工作区页 | 四个页签：改动（文件清单 + 逐行差异）/ 提交 / 历史 / 分支 |
| 指挥台页 | 四个页签：运行（每轮花了多少、从哪能重开）/ 评估 / 历史 / 架构 |
| 对话页左栏 | 新对话按钮 + 你的全部对话（可按名字旁边的小按钮重命名或删除） |
| 对话页顶栏 | 当前对话的标题；折叠左栏的按钮在这里 |
| 底部输入框 | 打字的地方；左边可以选模型、看上下文用了多少 |

## 窗口找不到了？

看右下角托盘里的 WorkBaby 图标，点它就能把窗口唤回来；彻底退出在托盘的右键菜单里。
