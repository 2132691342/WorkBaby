# 快速上手

WorkBaby 是 **PI** 的桌面界面。它不自己实现 AI：内核是外部 PI 进程，
WorkBaby 负责发现 / 安装 / 拉起 / 守护它，并把它的输出翻译成界面。

这台机器上的 `pi` 命令与 WorkBaby 共用同一份配置（`~/.pi/agent`），
所以你以前装的技能、插件、模型、MCP 服务，打开就能看见。

## 界面怎么走

```
顶栏   品牌 · 当前区标题 · 连接灯 · 窗控（不放导航）
左缘   一级导航 rail：对话 / 工作区 / 技能 / 用量 / 帮助 / 设置（图标+短标签竖排）
左栏   当前这一区的导航（会话列表 / 设置分组 / 文档目录）
主区   内容
```

- 所有一级入口都在左缘那条窄栏里，**设置与对话平级**，点图标下方的小字即可
- 左栏底部是**引擎状态卡**：谁在跑、什么模型、上下文多满，点一下直达模型服务设置
- 顶栏折叠钮收起左栏，给消息流让出宽度；底部状态条常驻显示模型与上下文水位

## 第一次打开

1. **环境向导**：依次检查运行时（Node）、助手（PI）、模型服务三项，卡在哪一步就停在哪一步
2. **装 PI**（如果还没有）：点一次「安装」，进度实时打印在下面
3. **配模型**：填一个兼容接口的地址与密钥即可。保存后写进 PI 的 `models.json`，命令行立刻也能用

三项都绿了才会放行到对话页。

## 问一句话

- 在底部输入框用大白话写需求，`Enter` 发送、`Shift+Enter` 换行
- 要让助手看某个文件，输入 `@` 逐级选文件；要用某个技能，输入 `/` 挑命令
- 回复过程中输入框变成「插话」模式：发出去的话在下一轮立刻生效；
  切到「排队」则等这一批处理完再进
- `Esc` 停下当前这一轮（输入框为空时才响应，免得误按）

## 它真的会动手

助手能读文件、改文件、跑命令——这些工具都在 PI 里，不是你装的另一个程序。

- 每一次工具执行都会显示成一张可展开的卡片：干了什么、参数、输出、耗时
- 有些插件会先问你一句（例如写入前确认），问题以卡片形式出现在对话末尾
- 改动可以在「工作区」页逐行对账，并在那里收成一次提交

## 换模型 / 换思考档

输入框下方的工具行里两枚开关：

- **模型**：左列服务商、右列模型，点一下就写回这条对话
- **思考档**：从「关闭」到「最大」。越深越慢越贵

两枚开关右侧是**上下文水位**：已用多少、窗口多大、到多少会自动整理。

## 找不到东西时

| 你要找 | 去哪 |
|---|---|
| 我的技能 | 设置 · 技能 |
| 装过的插件 / 包 | 设置 · 插件 |
| 模型服务 | 设置 · 模型服务 |
| 助手能用的工具 | 设置 · 工具 |
| MCP 外部工具 | 设置 · MCP |
| 花了多少钱 | 仪表盘 |
| 配置文件到底在哪 | 设置 · 行为（页底列出全部路径，点一下复制） |
