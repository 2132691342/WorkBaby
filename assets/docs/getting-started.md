# 快速上手

## 第一次启动

1. 双击 `WorkBaby.exe`，窗口会自己出现
2. 点左下角 **设置 → 模型服务**，选一个你常用的服务商模板（也可以自己填接口地址）
3. 去服务商官网申请一个 API Key，粘贴进去，点 **拉取模型列表**，勾一个模型，**保存**，再点 **测试**
4. 回到对话界面，直接说人话就行

## 日常使用

| 你想要 | 就这么说 |
|---|---|
| 读文件 | 「帮我看看桌面上那个报告文件夹里有什么」 |
| 处理表格 | 「把这个 Excel 按月份汇总，给我个总数」 |
| 写东西 | 「帮我写一封请假邮件，客气一点」 |
| 查资料 | 「搜一下今天的新闻，挑三条讲给我听」 |

- **发送**：回车；换行：Shift + 回车（可在 **设置 → 行为** 里改成 Ctrl + 回车 发送）
- 助手干活的每一步（读了哪个文件、跑了什么命令）都会展开成卡片，点开能看细节
- 想中途补充？直接打字发送，它会作为**插话**立刻生效
- 跑偏了？点 **停止**，重新说

## 窗口找不到了？

看右下角托盘里的 WorkBaby 图标，点它就能把窗口唤回来；彻底退出在托盘的右键菜单里。
