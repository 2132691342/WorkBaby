# 工具与安全

WorkBaby 能「干活」，靠的是给你装了一箱子工具。它每次动手前，
你都能在对话里看到一张卡片：干了什么、参数是什么、结果是什么。

## 它有哪些工具

| 类别 | 工具 | 用途 |
|---|---|---|
| 文件 | 读 / 写 / 编辑 / 列目录 / 查找 / 搜内容 | 读你的文档、改代码、找文件 |
| 命令 | 运行命令（PowerShell） | 跑系统命令，比如批量改名、查系统信息 |
| 代码 | 运行 Python | 算数、处理表格、画图 |
| 联网 | 网页搜索 / 抓取网页 | 查最新资料（需要联网） |
| 知识 | 知识库检索 | 在你放进来的资料里找答案 |

工具名单在**设置 → 工具**里能逐个看到：它是干什么的、风险多高、要不要先问你，
也可以在这里把某个工具停用。

## 再接进来的工具（MCP）

外面有人把一套工具打包成「MCP 服务」发布（操作浏览器、查数据库、连你自己的系统都行）。
WorkBaby 能把它们接进来，接进来之后就和上面这些工具一起出现在助手面前。

**设置 → MCP** 直接编辑一个 JSON 文件（`mcp.json`，就在本机数据目录里，
面板顶部会显示它的完整路径）。点「填入模板」挑一档，把命令换成你自己的：

```jsonc
{
  "mcpServers": {
    "我的服务": {
      "command": "npx",
      "args": ["-y", "@some/mcp-server", "D:\\资料"],
      "disabled": false
    }
  }
}
```

规则很少，就三条：

- **改完点「保存并重载」**：解析不过就一句「哪一段不合格」，不会把你原来能用的配置写坏
- 不想用了把 `disabled` 改成 `true`，不用删掉
- 外部工具的动作没人能替你预判，所以**一律每次先问**；全局启停在「工具」页

## 三级执行方式

**设置 → 行为 → 执行方式**，选一档：

| 档位 | 助手的行为 |
|---|---|
| 每次问我（默认） | 改文件、跑命令之前都弹一张卡问你：放行还是拒绝 |
| 自动改文件 | 改文件不再打断你；跑命令、跑脚本仍会问 |
| 全自动 | 什么都不问，直接干活（自担风险，建议熟悉后再用） |

审批卡片有三个按钮：

- **放行**：只允许这一次
- **本会话都放行**：这个对话里同类操作不再问
- **拒绝**：不执行，助手会换个办法或告诉你为什么没做

拒绝永远是安全的：助手只会收到一句「这个操作没做」，不会硬来。

## 独立对话怎么理解「工作目录」

助手读写的文件都在**工作目录**里。默认是你电脑的用户文件夹，
可以在**设置 → 行为 → 工作目录**改成一个你常放资料的地方。

Python 已经内置，助手要跑脚本时不需要你自己装环境；命令行用的是系统自带的 PowerShell。
在**设置 → 内置运行时**能看到当前实际用的是哪一份。

## 助手引擎用的是哪一份

干活的内核是一个外部的助手引擎。启动时按这个顺序找：

1. 你电脑上已经装过的那份（`pi` 命令能找到）
2. 程序内置的那份（用内置 Node 跑，装在应用数据目录里）

**优先用你自己装的那份**：它带你自己的包、你自己的版本，你在命令行里改的配置也认。
只有完全找不到时才会退到内置那份。当前实际用的是哪一份，
在**设置 → 内置运行时**的「助手引擎」一栏看得到。

要换模型服务，直接在 **设置 → 模型服务** 里配，两边读的是同一份配置文件——
你在界面里改的，命令行那边也生效。

## 数据在哪儿

- 对话记录、配置、密钥全部保存在本机 `%APPDATA%\WorkBaby\`
- API Key 用 AES-256 加密后存储，不会明文落盘
- 除了调用你配置的模型服务和网页搜索，不向外界发送任何内容
