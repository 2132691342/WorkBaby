# 技能

技能 = 一份带 frontmatter 的 SKILL.md，告诉助手某类任务怎么做、什么时候用它。

## 形态

```markdown
---
name: code-review
description: 对当前工作区做代码评审，输出分级问题清单
---

（正文：评审步骤、关注点、输出格式）
```

- `name` 即身份；`description` 决定模型何时想到它（必须 ≤1024 字符）。
- 三区来源：**内置包**（随应用分发，不可删）、**用户目录**、**工作区 `.workbaby/skills`**。同名时工作区 > 用户 > 内置。

## 启停

- 启用的技能以「可用技能清单」进系统提示词，模型按需读取正文。
- 停用即整体退出：不进清单、不可调用。
- 斜杠命令 `/skill:名字` 可显式触发某个技能。

## 导入

设置页支持从目录导入（含 SKILL.md 的文件夹）或 zip 包；重名会跳过并提示。
