# 知识库与技能

## 知识库

**设置 → 知识库 → 添加文档**（支持 md / txt / pdf / docx / xlsx / pptx / html / csv / json 等，
可以一次框选多个文件）。文档会被切成小块建好索引，之后问「根据我给的资料……」它就会自己去查。

- 检索在本地完成，不上传任何内容
- 文档列表里能看到状态与分块数量；失败会写明原因
- **重建索引**用于文档内容变化后刷新
- 二进制格式（PDF / Office）按页与段落抽取，抽出来的文字同样可检索

## 技能

技能 = 给助手看的「操作套路」，一段 Markdown。用上了它，助手就按你写的步骤做那一类事。

**不预置任何技能**：要用什么套路由你自己写、自己导入。
管理入口全在 **设置 → 技能**：新建 / 从文件夹导入 / 导入压缩包 / 启停 / 看正文 / 删除。

两种来源，同名时工作区的优先：

| 来源 | 位置 | 什么时候用 |
|---|---|---|
| 全局 | `%APPDATA%\WorkBaby\pi-agent\skills\` | 你希望每个项目都能用的套路 |
| 工作区 | `<工作区>\.pi\skills\` | 只在某个文件夹里用的套路 |

**这两个目录与助手命令行用的是同一份**：你在设置页建的技能落在全局目录，
从文件夹导入的项目技能落在工作区目录。因此如果你本来就在用 PI 的命令行，
两边看到的永远是同一批文件，不会出现「界面里有、助手不认」。

### 自己写一个

1. 设置 → 技能 → 新建技能
2. 填名字（小写字母、数字、连字符）、一句「什么时候用它」、步骤正文
3. 保存后立刻生效，不用重启

也可以手写：在上面任一目录建一个文件夹，放一个 `SKILL.md`，
开头用三横线包住名字与说明，正文写步骤。写了 `when_to_use` 触发词，
助手自己判断该不该用它的准确度会高一些。

### 停用是什么意思

助手只看目录里有什么，没有「已停用」这个开关。所以停用 = 把那个文件夹移出技能目录，
界面上的开关只是替你做这件事。想彻底不要了，就删除。

## 执行方式（审批）

**设置 → 行为 → 执行方式**

| 档位 | 行为 |
|---|---|
| 每次问我 | 改文件、跑命令前都先问一句，推荐 |
| 自动改文件 | 改文件不再打断，跑命令和跑脚本仍要审批 |
| 全自动 | 不再询问，直接执行（自担风险） |

选「每次问我」时，助手可能正在等你点「放行 / 拒绝」——
发送后一直转圈却没有回复，先看输入框上方有没有审批卡片。
