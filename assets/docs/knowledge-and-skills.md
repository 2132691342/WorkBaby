# 知识库与技能

## 知识库

设置 → 知识库 → **添加文档**（支持 md / txt / pdf / docx / xlsx / html / csv，
可以一次框选多个文件）。文档会被切成小块建好索引，
之后问「根据我给的资料……」它就会自己去查。

- 检索在本地完成，不上传任何内容
- 文档列表里能看到状态与分块数；失败会写明原因
- 「重建索引」用于文档内容变化后刷新

## 技能

技能 = 给助手看的「操作秘籍」，一段 Markdown：

- 内置技能开箱可用（办公文档处理、页面设计约束、教你写技能）
- 想自定义：在 `%APPDATA%\WorkBaby\skills\` 建一个文件夹，
  里面放一个 `SKILL.md`，写清「这个技能做什么、按什么步骤做」
- 写完重启即可看到；设置 → 技能 里可以随时开关
- 也可以在输入框打 `/技能名` 让它直接照着这个技能做

## 执行方式（审批）

设置 → 外观与行为 → 执行方式：

| 档位 | 行为 |
|---|---|
| 每次问我 | 改文件、跑命令前都先问一句，推荐 |
| 自动改文件 | 改文件不再打断，跑命令和跑脚本仍要审批 |
| 全自动 | 不再询问，直接执行（自担风险） |
