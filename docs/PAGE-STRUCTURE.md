# 页面结构

五个业务路由 + 未知路径兜底回首页；Frameless 窗口自绘标题栏 + 全局导航轨道 + 视图内面板。
设计对象是「第一次用 AI 的办公人员」：任何需要解释的控件都不许出现。

## 路由

| 路径 | 视图 | 说明 |
|---|---|---|
| `/` | `views/ChatView.vue` | 对话主界面；`/?session={id}` 打开任意会话，消费后清掉参数 |
| `/setup` | `views/SetupView.vue` | 环境向导：Node / PI / 模型。`bootstrap.pi_env.ready=false` 时强制进这里 |
| `/workspace` | `views/WorkspaceView.vue` | 工作区：改动 / 提交 / 历史 / 分支四个页签（specs/09） |
| `/dashboard` | `views/DashboardView.vue` | 仪表盘：token 与花费 |
| `/help/:name?` | `views/HelpView.vue` | 帮助文档（内置只读手册） |
| `/settings/:tab?` | `views/SettingsView.vue` | 设置（七个板块，tab 落在 URL 上） |

**没有「指挥台」**：运行记录、评估、通用历史、架构图这套自造概念已整体移除。
「看见并控制」的落地位置是对话页（工具卡 + 提问卡）、工作区页（改动对账）与仪表盘（用量），
而不是另开一个只有开发者看得懂的观测台。

## 全局骨架：标题栏 + 导航轨道

```
┌──────────────────────────────────────────────────────┐
│ titlebar：WB · WorkBaby │ [折叠钮] 会话标题 … 灯 · 窗控    │
├──┬───────────────────┬───────────────────────────────┤
│轨│     （视图内面板）    │          （视图主区）            │
│道│                   │                               │
└──┴───────────────────┴───────────────────────────────┘
```

- **标题栏**：品牌 + 中区（对话页显示当前会话标题与折叠按钮，其余页显示页面名）+ 右侧连接灯与窗口控制
- **导航轨道** `common/NavRail.vue`（56px）：五个入口（对话 / 工作区 / 仪表盘 / 帮助 / 设置）+ 底部主题切换；
  选中态 = 淡底 + 左侧 2px 竖条 + 主色图标与文字
- 视图切换带过渡：旧页淡出、新页自下方 6px 浮入，尊重 `prefers-reduced-motion`

│            │   ├ 多行输入 / @ 文件面板 / 斜杠命令  │

### 会话从哪来

会话列表读的是 **PI 的会话目录**（`~/.pi/agent/sessions/--<cwd>--/*.jsonl`）：

- 你在终端里用 `pi` 聊过的会话，这里同样看得到，点开就能接着聊；
- 列表按工作目录分组，标题取 `session_info` 的名字或首条用户消息，右侧是相对时间；
- 行悬停让位给三个动作：重命名 / 导出 HTML / 删除（导出与改名都落到 PI 的那条会话上）。

**「新对话」不建空会话**：PI 要等第一条消息才落盘，所以点新对话只是把界面切到草稿态；
第一次发送时由后端现场创建，返回体里带回真正建出来的 `session_id`。

**一个工作目录只有一个进程、一个当前会话**：同一目录下第二条对话要等第一条跑完（5005），
不同目录各自一个进程，互不影响。

### 流式呈现

| 状态 | 呈现 |
|---|---|
| 思考中 | 左侧竖线 + 「正在思考」+ 字数；只渲染尾部 4000 字 |
| 工具执行中 | 工具卡状态灯转圈，展开看参数与输出 |
| 正文流式 | 正文末尾常驻闪烁光标 |
| 自动重试中 | 流末尾一条淡黄提示条 + 「停止重试」按钮 |
| 输出被截断 | `stop_reason=length` 时给一条警告 + 「继续」按钮 |
| 引擎提问 | 流末尾一张提问卡：确认 / 单选 / 填空三种交互，拒绝永远安全 |

引擎提问（`chat:ask`）来自 PI 进程里的扩展，不挂在某一条消息上，因此统一排在流末尾；
回答走 `POST /chat/answer`，回给发出请求的那个进程。

### 回合分组

一次「提问 → 回答」是**一整块**：一个头像 + 一根不断的竖轨，思考、工具卡、正文都挂在这根线上。
回合内 8px 间距，回合间 24px——靠紧才看得出是同一个动作，靠松才看得出换了一次动作。

### 输入区

- 流式期间输入框变「插话」模式：发送 = 插话（PI 的 `steer`），Esc = 停止（输入框为空时）
- Ctrl+Enter = 排队（`follow_up`）
- `@` 唤起文件选择，`/` 唤起命令菜单：内置命令 + **PI 报上来的斜杠命令**（扩展命令与提示模板，标「插件 / 模板」）+ 已启用技能
- 模型 chip 两级面板：左列全部服务商、右列该服务商的模型；点选即写回这条会话
- 思考档 chip：`off` ~ `max`，点选即写回

## SetupView（环境向导）

`bootstrap.pi_env.ready=false` 时强制进这里。三步，按 `blocking` 直接落到卡住的那一步。

| 步骤 | 内容 | 失败时 |
|---|---|---|
| ① Node | 系统已有 22+ 就直接用；没有则用内置运行时 | 显示解压失败原因与 7002 / 7004 的处置动作 |
| ② PI | 显示探测到的 `pi_path` 与版本；没装则一个「安装」按钮，下方流式打印 npm 输出 | npm 原始输出尾部 + 「重试」 |
| ③ 模型 | 复用设置页的 Provider 面板 | 「至少配一个服务」的提示，不允许跳过 |

## WorkspaceView

助手干完活之后，「它到底动了什么」要有地方对账；改动也能在这一页收成一次提交。
页签四个：**改动 / 提交 / 历史 / 分支**。

- 看的是**当前会话的工作目录**（切会话即重载）
- 写入只开放受控六动作（stage / unstage / commit / 新建分支 / 切分支 / push），
  提交这一下永远由用户点下去；禁止清单见 specs/09
- 没装 Git 或不是仓库时给空态 + 一句可执行的下一步

## DashboardView

| 区域 | 内容 |
|---|---|
| 读数卡 | 总 token / 输入-输出 / 缓存命中率 / 花费 |
| 趋势图 | 近 N 天输入与输出双折线（SVG 自绘 + 面积） |
| 按模型 | 占比环（SVG 自绘），色取四档靛蓝色阶，最多六段其余归「其他」 |
| 会话榜 | 用量最高的 6 个会话，点击直达 |
| 天数切换 | 7 / 14 / 30 |

数据全部来自 PI 的会话文件（每条助手消息带 usage），没有用量时整页停在空态，不画空图表。

## SettingsView

七个板块，URL 是唯一真相（`/settings/:tab?`）。

| 板块 | 组件 | 要点 |
|---|---|---|
| 模型服务 | `ProviderPanel.vue` | 读写 PI 的 `models.json`：服务商卡片 + 编辑器（接口类型 / 地址 / 密钥 / 模型行）；测试连通、显式查看密钥、设默认、从上游拉模型清单 |
| 技能 | `SkillPanel.vue` | 按来源分组（我的技能 / 工作区 / 插件包）；开关 = 移目录；展开看正文；导入（整个技能目录一起复制）；删除（仅用户目录） |
| 插件 | `ExtensionPanel.vue` | 包（`pi install/remove`，输出流式打到面板）+ 扩展（目录 + 登记表启停、导入、删除）+ 重载 |
| 工具 | `ToolPanel.vue` | PI 当前声明的工具（内置 / 插件 / MCP），标注清单来自最近一次会话；开关写 `defaultTools` |
| MCP | `MCPPanel.vue` | 服务卡片（在线状态 + 工具数 + 登录/删除）+ 配置原文编辑（全局 / 项目两份）+ 重连 |
| 外观 | `AppearancePanel.vue` | 主题两套；字体五选一；字号四档；自定义背景；思考过程开关 |
| 行为 | `BehaviorPanel.vue` | 工作目录；默认思考档；压缩阈值；托盘 / 回车 / 开机启动；**页底列出 PI 的全部配置路径** |

**外观与行为必须分开**：用户找设置时是带着目的来的——「我想让它别老弹窗确认」和
「我想把界面调暗」是两件不相干的事。

七个面板用 `v-if` 懒挂载：只打开「外观」时不去拉模型服务与技能列表。

## HelpView

内置用户手册：左侧文档目录 + 右侧 Markdown 阅读，URL 是唯一真相（`/help/:name`）。
文档围绕「用界面操作 PI」重写：快速上手 / 模型服务 / 技能与插件 / 工具与 MCP / 用量与花费 / 常见问题。

## 设置项

| 键 | 取值 | 归属 |
|---|---|---|
| `theme` | `light` / `dark` | 外观 |
| `font_family` | `system` / `song` / `kai` / `hei` / `fang` | 外观 |
| `font_size` | `sm` / `md` / `lg` / `xl` | 外观 |
| `show_thinking` | `true` / `false` | 外观 |
| `minimize_to_tray` | `true` / `false` | 行为 |
| `send_on_enter` | `true` / `false` | 行为 |
| `workspace` | 绝对路径 | 行为 |
| `bg_image` / `bg_opacity` / `bg_blur` | 路径 / 0–0.9 / 0–24 | 外观 · 背景 |
| `context_window` | 整数 | 行为（手填覆盖 models.json 里的窗口） |

**不在设置页的东西**：默认模型、思考档、工具集、压缩参数全都写在 PI 的 `settings.json` 里，
由模型服务 / 工具 / 行为三个板块直接改那份文件——不存在「界面改了但助手行为不变」的第二份账。

## 图标纪律

全站只有一种图标语言：`AppIcon.vue` 里的内联 SVG，24 网格、1.7 描边（暗色主题 1.85）。
**禁止**用 Unicode 字符或 Emoji 冒充图标。
