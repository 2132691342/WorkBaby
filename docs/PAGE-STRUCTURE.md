# 页面结构

两个路由，侧栏 + 主区的桌面布局；Frameless 窗口自绘标题栏。
设计对象是「第一次用 AI 的办公人员」：任何需要解释的控件都不许出现。

## 路由

| 路径 | 视图 | 说明 |
|---|---|---|
| `/` | `views/ChatView.vue` | 对话主界面 |
| `/dashboard` | `views/DashboardView.vue` | 仪表盘：token 用量 |
| `/settings` | `views/SettingsView.vue` | 设置（四板块） |

## ChatView

```
┌──────────────────────────────────────────────┐
│ titlebar：WB · WorkBaby · 状态灯 · 最小/最大/关闭 │
├────────────┬─────────────────────────────────┤
│ 新对话      │ chat-head：会话标题               │
│ 会话列表    │─────────────────────────────────│
│ （今天/本周 │ MessageList                      │
│  /更早）    │   turn = 用户气泡 / 助手回答        │
│            │   + 工具执行卡 / 思考 / 流式         │
│ 仪表盘      │   + 审批决策卡（紧跟触发它的回合）   │
│ 设置        │─────────────────────────────────│
│            │ ChatInput                        │
│            │   ┌ 上下文水位条（极细，低透明度）    │
│            │   ├ 待发送附件 chip 列表            │
│            │   ├ 多行输入 / @ 引用 / 斜杠命令     │
│            │   └ 模型 chip · 规矩 chip · 发送/停止 │
└────────────┴─────────────────────────────────┘
```

- 无消息时显示欢迎区 + 四张例句卡（点击直接发送）
- 流式期间输入框变「插话」模式，可随时打断
- 消息列与输入框共用同一个 `max-width`，左右边缘对齐
- 标题栏右侧一枚连接状态灯：SSE 断开时转黄，不弹提示不打断
- **模型与执行方式两个切换入口在输入框内**，不在 chat-head——
  「用什么模型」「要不要先问我」都属于这一轮发送的上下文
- `@` 唤起文件选择，`/` 唤起命令菜单
- `chat:done` 后拉取会话权威快照，前端不做增量合并

## DashboardView

| 区域 | 内容 |
|---|---|
| 数字块 | 总 token / 输入输出 / 会话数 / 平均耗时 |
| 柱状图 | 近 N 天 token 用量（纯 CSS 高度条，无图表库） |
| 模型占比 | 按模型横向占比条，前 8 名 |
| 会话榜 | 用量最高的 5 个会话，点击跳转 |
| 天数切换 | 7 / 14 / 30 |

## SettingsView

| 板块 | 组件 | 要点 |
|---|---|---|
| 模型服务 | `ProviderPanel.vue` | 六个预设模板一键填；模型走下拉拉取，不手打；测试连通；设默认 |
| 技能 | `SkillPanel.vue` | 开关启停（落库）；展开看正文；显示来源 |
| 知识库 | `KnowledgePanel.vue` | 多选文件导入；状态与分块数；就地检索 |
| 外观与行为 | `AppearancePanel.vue` | 主题两套；执行方式三档；Python 状态；关于 |

四个面板用 `v-if` 懒挂载：只打开「外观」时不去拉模型服务和技能列表。

## 组件基元

| 组件 | 用途 |
|---|---|
| `common/EmptyState.vue` | 空态（图标 + 标题 + 副文案 + 动作） |
| `common/PageState.vue` | 列表三态：骨架 / 错误 / 空态 |
| `common/AppIcon.vue` | 唯一图标出口：内联 SVG，24 网格线性 |
| `chat/SessionList.vue` | 会话分组 + 重命名/删除 |
| `chat/ExampleCards.vue` | 首屏四张例句卡 |
| `chat/MessageList.vue` | 消息流 + 运行中回合 + 审批卡定位 |
| `chat/MessageItem.vue` | 单条消息（markdown / 思考折叠 / 复制） |
| `chat/ToolRunRow.vue` | 工具执行卡（折叠摘要 / 展开参数与输出 / 耗时） |
| `chat/ApprovalCard.vue` | 审批三选：只这次 / 本会话 / 拒绝 |
| `chat/ChatInput.vue` | 输入区（自动增高 / 回车发送 / 插话提示 / 上下文水位 / 模型与规矩 chip；`@` 附件 chip 内联在此） |

## 图标纪律

全站只有一种图标语言：`AppIcon.vue` 里的内联 SVG，24 网格、1.6 描边。
**禁止**用 Unicode 字符（`+` `⚙` `✎` `×` `▸` `…`）或 Emoji 冒充图标——
它们在不同 Windows 缩放比例与字体下会变形，且没有统一基线。
