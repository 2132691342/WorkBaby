# 页面结构

四路由 + 未知路径兜底回首页；Frameless 窗口自绘标题栏 + 全局导航轨道 + 视图内面板。
设计对象是「第一次用 AI 的办公人员」：任何需要解释的控件都不许出现。

## 路由

| 路径 | 视图 | 说明 |
|---|---|---|
| `/` | `views/ChatView.vue` | 对话主界面 |
| `/dashboard` | `views/DashboardView.vue` | 仪表盘：token 用量 |
| `/help/:name?` | `views/HelpView.vue` | 帮助文档（内置只读手册） |
| `/settings/:tab?` | `views/SettingsView.vue` | 设置（六个板块，tab 落在 URL 上） |

## 全局骨架：标题栏 + 导航轨道

```
┌──────────────────────────────────────────────────────┐
│ titlebar：WB · WorkBaby │ [折叠钮] 会话标题 … 灯 · 窗控    │
├──┬───────────────────┬───────────────────────────────┤
│轨│     （视图内面板）    │          （视图主区）            │
│道│                   │                               │
└──┴───────────────────┴───────────────────────────────┘
```

- **标题栏**：品牌 + 中区（对话页显示当前会话标题与折叠按钮，其余页显示页面名）+
  右侧连接灯与窗口控制；主题切换不在标题栏，移入轨道底部
- **导航轨道** `common/NavRail.vue`（56px）：四个入口 + 底部主题切换；
  选中态 = 淡底 + 左侧 2px 竖条 + 主色图标与文字；
  条目 = 图标 + 10px 小字标签（图标单靠猜对新手不友好）
- 轨道全站常驻：一级导航只有这一处，各视图不再自画返回入口

## ChatView

```
┌────────────┬─────────────────────────────────┐
│ 新对话      │ MessageList（直达顶部，无页面头）    │
│ 会话列表    │   turn = 用户气泡 / 助手回答        │
│ （今天/本周 │   + 工具执行卡 / 思考 / 流式         │
│  /更早，    │                                    │
│  时间在行尾，│   + 审批决策卡（紧跟触发它的回合）   │
│  悬停让位给 │─────────────────────────────────│
│  操作按钮）  │ ChatInput                        │
│            │   ┌ 上下文水位环 + 读数（常驻可见）   │
│            │   ├ 待发送附件 chip 列表            │
│            │   ├ 多行输入 / @ 文件面板 / 斜杠命令+技能 │
│            │   └ 模型 chip · 规矩 chip · 发送/停止 │
└────────────┴─────────────────────────────────┘
```

- 会话面板 `chat/SessionPanel.vue` 可折叠（标题栏按钮切换，状态记 localStorage）；
  折叠后消息区占满窗口
- 会话标题显示在标题栏中区（见上），消息区顶部不再有页面头

- 无消息时显示欢迎区：光晕背景 + badge 药丸 + 双色标题 + 四张例句卡（点击直接发送）；
  **没配默认模型时例句卡换成配置引导卡**（「去配置」直达模型服务页 + 「看教程」进帮助页）——
  否则第一条消息必然失败，而失败要在十几秒后才浮现，那一刻用户已经认定「这软件是坏的」
- 流式期间输入框变「插话」模式：发送 = 插话，**Esc = 停止**
  （仅在输入框为空时响应，避免误伤正在写的内容）
- 消息列与输入框共用同一个 `max-width`，左右边缘对齐
- 标题栏右侧：连接状态灯（SSE 断开时转黄，同时出一枚「正在重连」chip，不弹提示）
- **模型与执行方式两个切换入口在输入框内**——
  「用什么模型」「要不要先问我」都属于这一轮发送的上下文
- `@` 唤起文件选择，`/` 唤起命令菜单
- `chat:done` 后拉取会话权威快照，前端不做增量合并

### 流式呈现

流式输出是这个产品的主交互，三种状态必须一眼分得清：

| 状态 | 呈现 |
|---|---|
| 思考中 | 左侧竖线 + 「正在思考」+ 字数；只渲染尾部 4000 字（推理可能几万字，全量进 DOM 会卡，也会把正文顶出屏幕） |
| 工具执行中 | 工具卡状态灯转圈，展开看参数与输出 |
| 正文流式 | 正文末尾常驻光标（`::after` 闪烁），「还在写」不需要解释；正文一出现就自动收起思考块，视线落在答案上 |
| 输出被截断 | `stop_reason=length` 时在流末尾给一条警告 + 「继续」按钮（发一句「继续」续写）；警告里报出本轮实际下发的输出预算（按「窗口 1/8」派生，不可设置），撞硬上限时应换模型；出错时给「重试」 |

三者的先后顺序固定：思考 → 工具 → 正文。思考块在流式期间默认展开，
跑完随消息一起折起——推理过程默认可见，但不该在事后长期占屏。

### 回合分组

一次「提问 → 回答」是**一整块**，不是几条消息。数据层一次回答会落成多条
`assistant`（中间夹着工具结果），`turnBlocks` 按 user 消息把它们收成一个回合：
**一个头像 + 一根不断的竖轨**，思考、工具卡、审批卡、正文、消息操作全挂在这根线上。

| 归属 | 规则 |
|---|---|
| 回合内 | 8px 间距，靠紧才看得出是同一个动作 |
| 回合间 | 24px 间距，靠松才看得出换了一次动作 |
| 审批卡 | 收进触发它的那一段 `.turn-tools`，与工具卡同列同缩进 |
| 找不到触发点的审批 | 仍走 `.turn-appr`：吃竖轨与助手列缩进，不退回容器左边缘 |

最后一条是硬约束：审批卡一旦贴到容器左边缘，竖轨在它上方断掉，
它就成了不属于任何一回合的悬空元素——而它恰恰是这一回合里唯一需要用户拍板的一步。

## DashboardView

| 区域 | 内容 |
|---|---|
| 读数卡 | 横排四个 KPI：总 token / 输入-输出 / 缓存命中率 / 平均耗时；各带图标与一行注解 |
| 趋势图 | 近 N 天输入与输出双折线（SVG 自绘 + 面积），卡底一行给平均与峰值上下文、会话数 |
| 模型占比 | 按模型横向占比条，前 5 名（后端最多给 8 个，界面默认取 5） |
| 会话榜 | 用量最高的 5 个会话，点击跳转 |
| 天数切换 | 7 / 14 / 30 |

布局节奏：读数卡（横排）→ 趋势图（全宽大卡）→ 两个分布卡（并排）。
没有数据时整页停在空态，不画空图表。页面无内嵌侧栏（导航走轨道），内容全宽居中（max 1060）。

## HelpView

内置用户手册：左侧文档目录 + 右侧 Markdown 阅读，URL 是唯一真相（`/help/:name`）。

| 区域 | 内容 |
|---|---|
| 目录 | `GET /docs` 返回的内置文档，按「新手先读」排序；选中态与其他侧栏一致 |
| 正文 | `GET /docs/:name` 的 Markdown 走 `utils/md.ts` 渲染，复用 `.prose` 排版 |
| 直达 | 欢迎页「看教程」→ `/help/models`；文档随 exe 打包，离线可用 |

直接访问 `/help`（不带文档名）自动落到第一篇「快速上手」。

## SettingsView

六个板块，URL 是唯一真相（`/settings/:tab?`），刷新与前进后退都停在原处。
侧栏底部显示版本号（不再放「返回对话」——一级导航只有轨道一处）。

| 板块 | 组件 | 要点 |
|---|---|---|
| 模型服务 | `ProviderPanel.vue` | 服务商模板一键填；模型从「拉取模型列表」里勾选，也可以直接输入名字（代理改名的模型只能手填）；模型参数预填默认值（窗口 128000 / 温度 0.25 / Top P 0.75，目录认得出的显示识别值）；测试连通；设默认；已存密钥显示掩码，点眼睛显隐、点「更换」重填（留空保存则保持原密钥） |
| 技能 | `SkillPanel.vue` | 新建 / 导入技能包（.zip，前端读字节转 base64 上传）或单个 SKILL.md；开关启停（落库）；展开看正文；显示来源 |
| 知识库 | `KnowledgePanel.vue` | 多选文件导入；状态与分块数；就地检索 |
| 工具 | `ToolPanel.vue` | 按分类列出全部内置工具：用途、风险、是否要先问、参数；可逐个停用 |
| 外观 | `AppearancePanel.vue` | 主题两套；字体五选一；字号四档；思考过程开关 |
| 行为 | `BehaviorPanel.vue` | 执行方式三档；工作目录；托盘驻留与开机自启；回车发送；模型能力与窗口手填（按默认服务 + 模型查；输出预算按窗口 1/8 展示，被厂商硬上限钳住时补一句「已按厂商上限收紧」）；**高级折叠区**（步数上限 / 工具并发 / 上游等待秒数，前端范围校验、留空 = 恢复缺省）；内置运行时（Python / PowerShell 两行状态 + 重新检测）；关于 |

**外观与行为必须分开**：用户找设置时是带着目的来的——「我想让它别老弹窗确认」和
「我想把界面调暗」是两件不相干的事，挤在一屏里只会互相干扰。

六个面板用 `v-if` 懒挂载：只打开「外观」时不去拉模型服务和技能列表。

代价是六个板块各有自己的加载态与错误态，改一处公共控件要过六个面板；
且「按 URL 定位板块」意味着刷新与前进后退都走一遍完整装配，比纯前端切页慢一拍。

## 设置项

| 键 | 取值 | 归属 |
|---|---|---|
| `theme` | `light` / `dark` | 外观（标题栏快切药丸也写这个键） |
| `font_family` | `system` / `song` / `kai` / `hei` / `fang` | 外观 |
| `font_size` | `sm` / `md` / `lg` / `xl` | 外观 |
| `show_thinking` | `true` / `false` | 外观 |
| `permission` | `ask` / `auto_edit` / `yolo` | 行为 |
| `minimize_to_tray` | `true` / `false` | 行为 |
| `send_on_enter` | `true` / `false` | 行为 |
| `workspace` | 绝对路径 | 行为 |
| `context_window` | 整数 | 行为（手填覆盖内置目录，留空跟随目录） |
| `context_reserve_tokens` | 整数 | 行为（留空 = 跟随模型输出预算；手填值作为显式覆写，仅在配置接口层） |
| `disabled_tools` | 逗号分隔 | 经 `/tools/:name/toggle` 由服务端落库 |
| `disabled_skills` | 逗号分隔 | 经 `/skills/:id/toggle` 落库 |
| `default_provider` / `default_model` | provider id / 模型名 | 行为（在模型服务面板设默认时写入） |
| `max_turns` | 整数（缺省 64，4–512） | 行为 · 高级（失控护栏） |
| `tool_parallel` | 整数（缺省 4，1–16） | 行为 · 高级（并发上限） |
| `stream_idle_seconds` | 整数（缺省 300，夹取 5–1800） | 行为 · 高级（上游等待） |

高级三项放在收起的折叠区里：新手看不见就不用管；真需要调的人（长批处理、慢推理模型）
点开就是三个带范围校验的数字框，留空保存等于恢复缺省。

## 图标纪律

全站只有一种图标语言：`AppIcon.vue` 里的内联 SVG，24 网格、1.7 描边（暗色主题 1.85）。
**禁止**用 Unicode 字符（`+` `⚙` `✎` `×` `▸` `…`）或 Emoji 冒充图标——
它们在不同 Windows 缩放比例与字体下会变形，且没有统一基线。
