# 页面结构

六个业务路由 + 未知路径兜底回首页；Frameless 窗口自绘标题栏 + 全局导航轨道 + 视图内面板。
设计对象是「第一次用 AI 的办公人员」：任何需要解释的控件都不许出现。

## 路由

| 路径 | 视图 | 说明 |
|---|---|---|
| `/` | `views/ChatView.vue` | 对话主界面；`/?session={id}` 打开任意会话，消费后清掉参数 |
| `/setup` | `views/SetupView.vue` | 环境向导：装 Node / 装 PI / 配模型。`bootstrap.pi_env.ready=false` 时强制进这里 |
| `/workspace` | `views/WorkspaceView.vue` | 工作区：助手改了哪些文件、改了什么（只读） |
| `/console` | `views/ConsoleView.vue` | 指挥台：运行 / 评估 / 历史 / 架构 |
| `/console/:tab` | 同上（tab 落在 URL 上） | `runs` / `evals` / `history` / `archmap`；`/console/runs?run={id}` 直达那次运行的详情抽屉 |
| `/dashboard` | `views/DashboardView.vue` | 仪表盘：token 用量 + 最近运行概览（正在跑 / 失败 / 条数 / token） |
| `/help/:name?` | `views/HelpView.vue` | 帮助文档（内置只读手册） |
| `/settings/:tab?` | `views/SettingsView.vue` | 设置（八个板块，tab 落在 URL 上） |

## 全局骨架：标题栏 + 导航轨道

```
┌──────────────────────────────────────────────────────┐
│ titlebar：WB · WorkBaby │ [折叠钮] 会话标题 … 灯 · 窗控    │
├──┬───────────────────┬───────────────────────────────┤
│轨│     （视图内面板）    │          （视图主区）            │
│道│                   │                               │
└──┴───────────────────┴───────────────────────────────┘
```

- **标题栏**：品牌 + 中区（对话页显示当前会话标题与折叠按钮，其余页显示页面名）+
  右侧连接灯与窗口控制；主题切换在轨道底部
- **导航轨道** `common/NavRail.vue`（56px）：六个入口（对话 / 工作区 / 指挥台 / 仪表盘 / 帮助 / 设置）+ 底部主题切换；
  选中态 = 淡底 + 左侧 2px 竖条 + 主色图标与文字；
  条目 = 图标 + 10px 小字标签（图标单靠猜对新手不友好）
- 轨道全站常驻：一级导航只有这一处，各视图不再自画返回入口
- 视图切换带过渡：旧页淡出、新页自下方 6px 浮入（半档动效内完成，尊重
  `prefers-reduced-motion`）；对话页「欢迎态 ↔ 消息流」互换、新回合入场、
  工具卡展开同规则——过渡只解释「刚才发生了什么」，不做无触发的装饰动画

## ChatView

```
┌────────────┬─────────────────────────────────┐
│ 新对话      │ MessageList（直达顶部，无页面头）    │
│ 会话列表    │   turn = 用户气泡 / 助手回答        │
│ （今天/本周 │   + 工具执行卡 / 思考 / 流式         │
│  /更早，    │                                    │
│  时间在行尾，│   + 审批决策卡（紧跟触发它的回合）   │
│  悬停让位给 │─────────────────────────────────│
│  操作按钮）  │ ChatInput                        │
│            │   ┌ 上下文水位环 + 读数（常驻可见）   │
│            │   ├ 待发送附件 chip 列表            │
│            │   ├ 多行输入 / @ 文件面板 / 斜杠命令+技能 │
│            │   └ 模型 chip · 规矩 chip · 发送/停止 │
└────────────┴─────────────────────────────────┘
```

- 会话面板 `chat/SessionPanel.vue` 可折叠（标题栏按钮切换，状态记 localStorage）；
  折叠走负边距滑出过渡（`v-show` 的 display 切换没有过渡），折叠后消息区占满窗口；
  列表一条会话都没有时给空态（图标瓦片 + 「还没有对话」），不留白板
- 会话标题显示在标题栏中区（见上），消息区不设页面头

- 无消息时显示欢迎区：光晕背景 + badge 药丸 + 双色标题 + 四张例句卡（点击直接发送）；
  **环境未就绪时例句卡换成配置引导卡**（「去配置」直达 `/setup`）——
  否则第一条消息必然失败，而失败要在十几秒后才浮现，那一刻用户已经认定「这软件是坏的」
- 流式期间输入框变「插话」模式：发送 = 插话（PI 的 `steer`），**Esc = 停止**
  （仅在输入框为空时响应，避免误伤正在写的内容）；Ctrl+Enter = 排队（`follow_up`）
- 消息列与输入框共用同一个 `max-width`，左右边缘对齐
- 标题栏右侧：连接状态灯（SSE 断开时转黄，同时出一枚「正在重连」chip，不弹提示）
- **模型与执行方式两个切换入口在输入框内**——
  「用什么模型」「要不要先问我」都属于这一轮发送的上下文。模型 chip 打开**两级级联面板**：
  左列一次列全部服务商（当前会话所在服务商排最前并点标），右列是该服务商的模型 + 名称过滤 +
  窗口/识图/工具能力标签；点选即写回会话的 `provider_id` 与 `model`，因此**任意旧对话都能直接
  切到任意服务商的任意模型**（含新增的），不必新开会话。每次打开重新拉取服务商列表，
  设置页刚加的厂商 / 模型即刻可选。
- `@` 唤起文件选择，`/` 唤起命令菜单
- `chat:done` 后拉取会话权威快照，前端不做增量合并

### 流式呈现

流式输出是这个产品的主交互，三种状态必须一眼分得清：

| 状态 | 呈现 |
|---|---|
| 思考中 | 左侧竖线 + 「正在思考」+ 字数；只渲染尾部 4000 字（推理可能几万字，全量进 DOM 会卡，也会把正文顶出屏幕） |
| 工具执行中 | 工具卡状态灯转圈，展开看参数与输出 |
| 正文流式 | 正文末尾常驻光标（`::after` 闪烁），「还在写」不需要解释；正文一出现就自动收起思考块，视线落在答案上 |
| 自动重试中 | 流末尾一条淡黄提示条：「上游拒绝，正在重试（2/3）」——PI 的自动重试可能持续几秒到几十秒，**没有这条提示界面看上去就是卡死** |
| 输出被截断 | `stop_reason=length` 时在流末尾给一条警告 + 「继续」按钮；警告里报出本轮实际下发的输出预算，撞硬上限时应换模型；出错时给「重试」 |

三者的先后顺序固定：思考 → 工具 → 正文。思考块在流式期间默认展开，
跑完随消息一起折起——推理过程默认可见，但不该在事后长期占屏。

### 回合分组

一次「提问 → 回答」是**一整块**，不是几条消息。数据层一次回答会落成多条
`assistant`（中间夹着工具结果），`turnBlocks` 按 user 消息把它们收成一个回合：
**一个头像 + 一根不断的竖轨**，思考、工具卡、审批卡、正文、消息操作全挂在这根线上。

| 归属 | 规则 |
|---|---|
| 回合内 | 8px 间距，靠紧才看得出是同一个动作 |
| 回合间 | 24px 间距，靠松才看得出换了一次动作 |
| 审批卡 | 收进触发它的那一段 `.turn-tools`，与工具卡同列同缩进 |
| 找不到触发点的审批 | 仍走 `.turn-appr`：吃竖轨与助手列缩进，不退回容器左边缘 |

最后一条是硬约束：审批卡一旦贴到容器左边缘，竖轨在它上方断掉，
它就成了不属于任何一回合的悬空元素——而它恰恰是这一回合里唯一需要用户拍板的一步。

## SetupView（环境向导）

`bootstrap.pi_env.ready=false` 时强制进这里。三步，按 `blocking` 直接落到卡住的那一步。

| 步骤 | 内容 | 失败时 |
|---|---|---|
| ① Node | 内置 Node 已解压就直接过；缺失则显示“正在准备运行时”与解压进度 | 「内置运行时不可用」+ 具体原因（归档缺失 / LFS 指针 / 解压失败），给 7002 / 7004 的处置动作 |
| ② PI | 显示探测到的 `pi_path` 与版本；没装则一个「安装」按钮，下方流式打印 npm 输出 | 「安装失败」+ npm 原错��尾部 + 「重试」 |
| ③ 模型 | 复用设置页的 Provider 面板（同一个组件，不复制） | 「至少配一个服务」的提示，不允许跳过 |

三步全部通过后自动进 `/`。**向导不提供“稍后再说”**：没有 PI 就没有对话，
留一个可以待着的空壳只会让用户以为程序坏了。

## WorkspaceView

助手干完活之后，「它到底动了什么」要有地方对账。左列是改动文件，右列是所选文件的逐行差异。

| 区域 | 内容 |
|---|---|
| 分支条 | 分支名 + 与上游的领先 / 落后 + 工作目录绝对路径（过长省略） |
| 改动列表 | 每个文件一行：短路径 + 状态标签（改过 / 新增 / 删除 / 改名 / 未跟踪）+ 增删行数；选中态 = 淡底 + 左侧 2px 主色竖条 |
| 差异区 | 等宽两栏（旧 / 新行号 + 正文）：新增淡绿底、删除淡红底、段头中性淡底；截断时卡底写明还有多少行 |
| 刷新 | 手动刷新（状态不自动轮询：仓库状态不会自己变，变的只有助手的行为） |

- 没装 Git 或工作目录不是仓库时给**空态 + 一句可执行的下一步**（「装上 Git 并在该目录执行 `git init`」），
  不留一个空列表让人以为程序坏了
- 看的是**当前会话的工作目录**（切会话即重载）：会话自己选过目录时，全局目录不是改动发生的地方
- 只看不写：这一页没有提交 / 回滚入口——写版本历史由用户自己的 Git 工具决定
- 长路径只留末尾两段（`…/dir/file`），完整路径在行 `title` 里

## DashboardView

| 区域 | 内容 |
|---|---|
| 读数卡 | 横排四个 KPI：总 token / 输入-输出 / 缓存命中率 / 平均耗时；各带图标与一行注解 |
| 趋势图 | 近 N 天输入与输出双折线（SVG 自绘 + 面积），卡底一行给平均与峰值上下文、会话数 |

| 天数切换 | 7 / 14 / 30 |

布局节奏：读数卡（横排）→ 趋势图（全宽大卡）→ 两个分布卡（并排）。
没有数据时整页停在空态，不画空图表。页面无内嵌侧栏（导航走轨道），内容全宽居中（max 1060）。

## HelpView

内置用户手册：左侧文档目录 + 右侧 Markdown 阅读，URL 是唯一真相（`/help/:name`）。

| 区域 | 内容 |
|---|---|
| 目录 | `GET /docs` 返回的内置文档，按「新手先读」排序；选中态与其他侧栏一致 |
| 正文 | `GET /docs/:name` 的 Markdown 走 `utils/md.ts` 渲染，复用 `.prose` 排版 |
| 直达 | 欢迎页「看教程」→ `/help/models`；文档随 exe 打包，离线可用 |

直接访问 `/help`（不带文档名）自动落到第一篇「快速上手」。

## SettingsView

八个板块，URL 是唯一真相（`/settings/:tab?`），刷新与前进后退都停在原处。
侧栏底部显示版本号；一级导航只有轨道一处，设置页不放返回入口。

| 板块 | 组件 | 要点 |
|---|---|---|
| 模型服务 | `ProviderPanel.vue` | 服务商模板一键填；模型从「拉取模型列表」里勾选，也可以直接输入名字；**模型参数与能力**每模型一行（上下文窗口 / 最大输出 / 工具调用 / 图片输入 / 推理 / 温度 / Top-P）；测试连通；设默认；已存密钥显示掩码，点眼睛显隐；**保存后自动写进 PI 的 `models.json`**（唯一写入者，specs/07） |
| 技能 | `SkillPanel.vue` | 新建 / 导入技能包（.zip，前端读字节转 base64 上传）或单个 SKILL.md；开关启停（落库）；展开看正文；显示来源 |
| 知识库 | `KnowledgePanel.vue` | 多选文件导入；状态与分块数；就地检索；**重建索引是后台任务**：点一下启动，之后按 700ms 轮询进度条（`done+failed / total`）并可「停止」；被中断时如实说「重建已中断（n/total）」 |
| 记忆 | `MemoryPanel.vue` | 一条一行：内容（双击就地改）、来源标签（我写的 / 助手记的）、生效状态；可停用（停用不删除，停用的不进提示）、可删除（两段确认）；顶部一条输入框直接添加 |
| 工具 | `ToolPanel.vue` | 按分类列出 PI 当前声明的工具（内置 + MCP + 扩展）：用途、风险、是否要先问、参数；可逐个停用（写 PI 的 `defaultTools`） |
| 外观 | `AppearancePanel.vue` | 主题两套；字体五选一；字号四档；**自定义背景**（选图 → 浓度 / 模糊各三档 → 清除）；思考过程开关 |
| 行为 | `BehaviorPanel.vue` | 审批档三档（`auto` / `ask_write` / `readonly`）；工作目录；执行记录保留期（天数 + 立即归档）；托盘驻留与开机自启；回车发送；模型能力与窗口手填；思考档位（`off`~`max`）；**高级折叠区**（压缩保留量 / 保留最近量）；内置运行时（Node / Python 两行状态 + 重新检测 + PI 版本与更新）；关于 |
| MCP | `MCPPanel.vue` | **编辑 `mcp.json`**（左侧原始 JSON，右侧解析结果对照）；「填入模板」三档；保存 = 校验 + 落盘 + 重载 PI；每条只标「已声明 / 内核已注册」（连接结果不可知，所以不画状态灯），配一个「重新加载」动作；内置的 `workbaby-knowledge` 单列成「内置能力」区（不可删）；未知字段原样保留 |

**外观与行为必须分开**：用户找设置时是带着目的来的——「我想让它别老弹窗确认」和
「我想把界面调暗」是两件不相干的事，挤在一屏里只会互相干扰。

八个面板用 `v-if` 懒挂载：只打开「外观」时不去拉模型服务和技能列表。

代价是八个板块各有自己的加载态与错误态，改一处公共控件要过八个面板；
且「按 URL 定位板块」意味着刷新与前进后退都走一遍完整装配，比纯前端切页慢一拍。

## ConsoleView（指挥台）

一级导航轨道新增「指挥台」入口（对话 / 工作区 / 指挥台 / 仪表盘 / 帮助 / 设置）。
视图内左侧子导航（`.nav-item` 同一竖条语言），右侧主区，四个页签：

```
┌──┬──────────────────────────────────────┐
│轨│  运行 │ 评估 │ 历史 │ 架构            │
│道│ ┌──────────────────────────────────┐ │
│  │ │  主区（按页签切换，带过渡）            │ │
│  │ │  运行：记录列表 + 详情抽屉            │ │
│  │ │  评估：记录列表 + 基线 + 对比         │ │
│  │ │  历史：来源分组 + 只读阅读 + 接着聊   │ │
│  │ │  架构：分层依赖图（自绘 SVG）+ 覆盖率 │ │
│  │ └──────────────────────────────────┘ │
└──┴──────────────────────────────────────┘
```

| 页签 | 组件 | 要点 |
|---|---|---|
| 运行 | `console/RunsPanel.vue` | 记录列表（状态灯 / 会话名 / 模型 / 轮次 / token / 时间）；进行中的行进会自动刷新（4s 轮询，仅在有 running 时）；点一行开右侧详情抽屉 |
| 运行 · 详情 | 同上抽屉 | 指标格（状态 / 收尾原因 / 模型 / 轮次 / 耗时 / token / 缓存命中 / 输出预算 / 压缩次数 / 峰值上下文）；「干了什么」时间线；上下文水位条（每轮一张快照）；「回到某一轮」列表（回到这里 / 开分支） |
| 执行时间线 | `console/RunTimeline.vue` | 一次 run 的瀑布条：每个工具动作按开始时刻与耗时落位；会话归档后它是「当时干了什么」的唯一凭据 |
| 评估 | `console/EvalsPanel.vue` | 评分（1–5 星点选）+ 批注；「存为基线」按钮；与基线差值列（绿降红升） |
| 历史 | `console/HistoryPanel.vue` | 来源筛选 + 搜索；点开只读渲染；「接着聊」弹窗（补一句下一步） |
| 架构 | `console/ArchMapPanel.vue` | 目录选择 + 分析进度；分层 SVG 图；点节点出侧栏（文件清单 / 被依赖次数）；覆盖率一行 |

子代理不单独占页签：它在对话里以工具卡出现（结论直接回填进主上下文），
它的运行记录与检查点跟普通 run 一样进「运行」页签。

| `bg_image` / `bg_opacity` / `bg_blur` | 路径 / 0–0.9 / 0–24 | 外观 · 背景（经 `/settings/background` 落库，图片先复制进数据目录） |
| `disabled_tools` | 逗号分隔 | 经 `/tools/toggle/:name` 由服务端落库 |
| `disabled_skills` | 逗号分隔 | 经 `/skills/toggle/:id` 落库 |
| `default_provider` / `default_model` | provider id / 模型名 | 行为（同时写 PI `settings.json` 的 `defaultProvider` / `defaultModel`） |
| `thinking_level` | `off`~`max` | 行为（写 PI `settings.json` 的 `defaultThinkingLevel`） |
| `default_tools` | JSON 数组 | 经 `/tools/toggle/:name` 写 PI `settings.json` 的 `defaultTools` |
| `orchestra_retention_days` | 整数（缺省 30，0–3650；0 = 永久） | 行为（隐藏会话按它归档，另配「立即归档」按钮） |
| `history_folders` | JSON 数组 | 指挥台 · 通用历史（用户自加的历史目录，非 `Setting*` 常量） |

高级两项放在收起的折叠区里：新手看不见就不用管；真需要调的人
（老被压缩的长对话）点开就是两个带范围校验的数字框，留空保存等于恢复缺省。

设置项只到「压缩保留量 / 保留最近量」为止。步数上限、工具并发、上游等待这三类
内核参数不在这里出现：它们由 PI 管，WorkBaby 没有协议面可写，摆一个框只会变成假开关。

## 图标纪律

全站只有一种图标语言：`AppIcon.vue` 里的内联 SVG，24 网格、1.7 描边（暗色主题 1.85）。
**禁止**用 Unicode 字符（`+` `⚙` `✎` `×` `▸` `…`）或 Emoji 冒充图标——
它们在不同 Windows 缩放比例与字体下会变形，且没有统一基线。
