# 错误码 · ERROR-CODES

码值为数字字符串，随 `Resp.code` 下发；`"0"` 为成功。段位见 `AGENTS.md` §2.4。
处置列是前端应展示的动作提示。

## 1000–1999 通用 / 文件 / 路径

| 码 | 含义 | 处置 |
|---|---|---|
| 1001 | 参数缺失或非法 | 检查表单 |
| 1002 | 文件读写失败 | 查看文件是否被占用 |
| 1003 | 路径越界（逃出允许根） | 换工作目录内路径 |
| 1004 | 路径不存在 | 确认路径 |
| 1005 | 目录不为空 / 操作冲突 | 清理后重试 |
| 1017 | git 命令失败（通用） | 看详情里的 stderr |
| 1020 | git 提交失败 | 检查暂存区与用户名配置 |
| 1021 | 合并/变基冲突未解决 | 先解决冲突 |
| 1024 | 远端领先（push 被拒） | 先 pull |
| 1027 | 强制推送被拒（无租约/未确认） | 刷新后用带租约推送 |
| 1030 | 压缩包解析失败 | 检查 zip 结构 |

## 2000–2999 配置 / 持久化 / DB

| 码 | 含义 | 处置 |
|---|---|---|
| 2001 | 配置文件损坏（JSON 解析失败） | 用详情定位行，修复或重置 |
| 2002 | 数据库打开/迁移失败 | 查看日志 |
| 2003 | 设置键非法 | — |
| 2004 | 数据目录不可写 | 检查磁盘与权限 |

## 3000–3999 Provider / 模型

| 码 | 含义 | 处置 |
|---|---|---|
| 3001 | provider 不存在 | 检查配置 |
| 3002 | 模型不存在 | 刷新模型清单 |
| 3003 | API key 缺失 | 填密钥 |
| 3004 | 默认模型未设置 | 去设置服务商页 |
| 3005 | baseUrl 非法 | 检查地址 |
| 3109 | provider 校验失败（字段缺失） | 补全表单 |
| 3113 | 密钥格式非法 | 检查密钥 |
| 3111 | 名称重复 | 换名 |
| 3200 | 模型连通测试失败 | 看详情（401/404/网络） |

## 5000–5999 会话运行

| 码 | 含义 | 处置 |
|---|---|---|
| 5001 | 会话忙（已有 run 在跑） | 等待或先停止 |
| 5002 | 会话不存在 | 刷新列表 |
| 5003 | 会话文件被占用/删除失败 | 等运行结束再删 |
| 5004 | 队列已满 | 稍后再发 |
| 5005 | 内核提问已过期 | 重新发起 |
| 5006 | 压缩失败 | 重试或减少保留量 |
| 5100 | 内核未就绪（未配模型） | 先配置模型 |

## 7000–7999 工具执行与外部进程

| 码 | 含义 | 处置 |
|---|---|---|
| 7001 | 命令执行超时 | 放宽 timeout 或拆任务 |
| 7002 | 命令被取消 | — |
| 7003 | 工具不存在/已停用 | 检查工具开关 |
| 7004 | 工具参数校验失败 | 看详情 schema 提示 |
| 7100 | LSP server 启动失败 | 确认语言服务器已安装并在 PATH |
| 7101 | LSP server 返回错误响应 | 看详情里的 server 消息 |
| 7102 | 语言服务器未安装 | 装上对应 server（或关掉 lsp 功能） |
| 7103 | 没有匹配该文件类型的语言服务器 | 换文件类型或配自定义 server |
| 7200 | 沙箱解释器不可用 | 装上对应运行时（node/python/…） |
| 7201 | 沙箱执行超时 | 拆小任务或调大 timeout |
| 7300 | 知识库操作失败 | 查看日志 |

## 8000–8999 Skill

| 码 | 含义 | 处置 |
|---|---|---|
| 8001 | SKILL.md 解析失败 | 检查 frontmatter |
| 8002 | description 缺失或超长 | 补全（≤1024 字符） |
| 8003 | 技能名非法（小写字母数字连字符） | 改名 |
| 8004 | 技能名冲突 | 内置/用户同名，改目录名 |
| 8005 | 内置技能不可删改 | — |
| 8006 | 导入失败（非目录/非 zip） | 检查来源 |

## 9100–9199 MCP

| 码 | 含义 | 处置 |
|---|---|---|
| 9101 | server 配置非法 | 检查 mcp.json |
| 9102 | server 启动失败/超时 | 确认命令可用；看 mcp 日志 |
| 9103 | 工具调用失败 | 看 server 返回 |
| 9104 | server 名冲突 | 改名 |

## 9700–9799 内核

| 码 | 含义 | 处置 |
|---|---|---|
| 9701 | 会话文件损坏（回放失败） | 用详情定位坏行；可从上一条目继续 |
| 9702 | 上下文溢出且压缩后仍超 | 减小 keepRecent 或新开会话 |
| 9703 | 模型流中断（不可重试） | 重发消息 |
| 9704 | 子代理启动失败 | 看详情 |
| 9705 | 内部一致性破坏（切点/树结构） | 备份后反馈日志 |
