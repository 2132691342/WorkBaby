# WorkBaby · 界面原型说明

这是**动手改前端之前**用来定方案的可交互原型：新视觉、新信息架构、全部交互都在里面。
共 40 屏，覆盖聊天主链路、设置中心 19 个页、桌宠窗口与各类浮层。

## 一、怎么看

> 不想打开页面？`screens/` 目录下已有 5 张关键界面截图：
> `map.png`（界面地图）、`chat-live.png`（会话进行中 · 浅色）、`chat-dark.png`（同一屏 · 暗色）、
> `set-models.png`（模型服务）、`pet-desktop.png`（桌宠窗口）。

1. 双击打开 `prototype/index.html`（推荐 Chrome / Edge，本地直接打开即可，无需装任何东西）。
2. 打开后第一屏是**界面地图**：40 张卡片按分组铺开，每张卡片有一句说明。点卡片进入该界面。
3. 每个界面**可以直接操作**：发消息、点审批按钮、切设置项、开右侧面板、切深浅色。
4. 顶部黑色**导览条**是原型专用（不属于产品界面）：`界面地图` 随时返回总览，
   `←` `→` 翻上一屏 / 下一屏，中间显示当前屏名、序号与一句话说明。

## 二、这一版设计的方向

一句话：**保留你喜欢的蓝白玻璃质感，把「三套语言拼贴」收敛成一套系统。**
浅色 = **晴空玻璃**（淡蓝渐变底 + 白色卡片 + 亮蓝强调）；
暗色 = **紫夜玻璃**（近黑底 + 暗紫光晕 + 紫罗兰强调）。

现状 UI 的问题不是不好看，而是**没有系统**：Element Plus 原生控件、自研玻璃拟态、
手写 scoped 样式三套语言混用；圆角 6~20px 随意取，字号 9~13.5px 半像素阶梯，
主色 / 薄荷 / 薰衣草 / 天蓝 / 柠檬 / 琥珀六色既当语义又当装饰，
空态、开关、徽标各有 2~4 种实现。

这一版把它收敛成可执行的规则：

| 维度 | 规则 |
|---|---|
| 色板 | 蓝 / 紫是唯一强调色（浅色亮蓝 `#2f7bf6` / 暗色紫罗兰 `#8b5cf6`）+ 两盏状态灯（绿=通过 / 红=出错），其余全是中性灰阶 |
| 分层 | 背景只留一层极淡的主色晕（**不做三色光晕**）；面板是雾面玻璃（模糊 + 半透明）；卡片是**不透明 + 1px 中性描边 + 极轻阴影** |
| 降噪 | 描边一律中性半透明（禁彩色描边）；按钮一律纯色（禁渐变）；选中态 = 中性底 + 一条主色标记（不再"底色 + 边框 + 彩字"三件套）；悬浮不做位移 |
| 图标 | 统一用 **Lucide**（24 网格 / 统一笔画 1.7 / 内联离线）——自绘线条几何不精确，是"业余感"最直接的来源；换图标集用 `prototype/tools/gen-icons.ps1` 重新生成 |
| 控件 | 按钮的实体感来自「1px 内高光 + 精确阴影 + 按下沉降 0.5px」，不用渐变；输入聚焦是 1px 主色 + 3px 淡光；分段控件选中是"抬起的白片"而非彩色块 |
| 字体 | 3 族 6 级：UI 用系统无衬线，标题与读数用 Bahnschrift（DIN 风），路径 / ID / token 用 Cascadia Code |
| 圆角 | 4 级（6 / 8 / 10 / 16px）+ 胶囊；圆润靠圆角与阴影，不靠描边 |
| 控件高度 | 3 档（24 / 30 / 34px）+ 28px 图标钮 |
| 动效 | 110 / 160 / 240ms 三档，只解释状态变化，不做装饰 |
| 主题 | 浅色=晴空玻璃，暗色=紫夜玻璃（默认浅色，与参考稿一致） |

两套主题共用同一组语义令牌，组件不写死色值——这解决了现有实现"暗色漏白"的根因。

## 三、交互上做的几个决定（原型里可直接体验）

- **聊天是一条流水线**：工具调用不是折叠卡片堆，而是左侧连续竖轨 + 节点状态灯 + 等宽行文，
  一眼能看出"跑到第几步、哪一步慢、哪一步失败"。
- **审批是一张带上下文的卡**：命令、工作目录、风险等级、已等待时长，按钮是
  `拒绝 / 本会话允许 / 仍要批准`；拒绝是回执不是错误，模型会改道。
- **输入区一排放得下**：模型 / 权限 / 参数 / 命令 / 引用 / 上下文环 / 发送，
  流式时自动变成 `插入（steer）+ 停止` 双键。
- **设置左导航一级化**：原设计是"4 个分组按钮 + 顶部 chip 二次选择"，要两跳才能到目标页；
  现在全部子项直接列出。
- **右侧面板统一**：工作区 / 变更 / 后台任务 / 辅助对话，同一位置、同一宽度、同一关闭方式。

## 四、40 屏清单

**对话工作区（6）**

| 屏 | 说明 |
|---|---|
| 空态 · 新任务 | 草稿态不落库；四张示例卡可直接起一个任务 |
| 会话进行中 | 一轮完整 run：思维链折叠、工具时间线、变更聚合、用量徽标 |
| 流式执行中 | 工具运行中 + 正文边出边渲染；可插话、可排队、可停止 |
| 审批暂停 | 危险命令停下来问：拒绝 / 本会话允许 / 仍要批准 |
| 目标模式 | 目标卡 + 待办推进 + 计划胶囊；未达成自动续跑 |
| 中断与恢复 | 停止原因横幅，「继续」从检查点续跑 |

**输入区与浮层（6）**：斜杠命令、@ 引用、模型选择、采样参数、上下文占用、命令面板（Ctrl+K）

**右侧面板（4）**：工作区（目录树 / 产物 / 预览）、变更与产物（diff / 回滚）、后台任务、辅助对话

**设置中心（19）**

| 组 | 页 |
|---|---|
| 模型 | 模型服务（Provider / 预设 / 熔断）、网络搜索 |
| 能力 | 工具、技能、MCP 服务、子智能体、自定义命令、用户钩子 |
| 数据 | 记忆中心、知识库、仓库导读、文件、仪表盘、运行历史 |
| 系统 | 外观、安全与高级（exec 白名单 / 免审授权）、桌宠、文档、关于 |

**独立窗口与系统（5）**：桌宠窗口、托盘与系统集成、启动引导、启动失败、设计系统（色板 / 字体 / 控件总览）

## 六、落地状态

这套语言已落到 `frontend/src`，与原型的对应关系：

| 原型 | 前端实现 |
|---|---|
| `css/tokens.css` | `src/themes.css`（`--wb-*` 语义令牌，`useTheme.ts` THEMES 为预览视图） |
| `css/base.css` + `css/glass.css` | `src/wb-ui.css`（组件语法唯一实现处） |
| `css/shell.css`（标题栏 / 侧栏 / 主区 / 设置两栏） | `wb-ui.css` 外壳段 + `App.vue` / `SettingsView.vue` |
| `css/screens.css`（工具时间线 / 审批 / 输入区） | `wb-ui.css` 聊天段 + `MessageBlocksRenderer` / `ApprovalInline` / `ChatInput` |

关键对齐点：

- **令牌**：浅色 = 晴空（`--wb-primary: #2f80ed`），暗色 = 紫夜（`#7c5cf8`）；圆角 6/8/10/16 + 胶囊；
  控件高度 26/34/38/44 + 32 图标钮；动效 110/160/240ms。色值只写在 `themes.css`。
- **组件语法**：按钮胶囊镂空（主操作主色描边，实底只出现在 hover）；卡片不透明 + 1px 中性描边 +
  极轻阴影；标签降噪为灰底灰字；状态灯去掉彩色光晕；开关加大并带白色对勾。
- **结构**：设置左导航一级化（19 个子项直接列出，分组标题只做视觉断行）；
  聊天工具调用改为「左侧竖轨 + 节点状态灯 + 等宽行文」的时间线；审批是一张带上下文的卡
  （命令 / 工作目录 / 风险 / 已等待 + 拒绝 / 本会话允许 / 仍要批准）。
- **降噪**：移除三色漂浮光球与多色光晕装饰；`--wb-grad-*` 置为 none（保留变量名以免破坏存量引用）；
  图标带淡底容器的做法保留在侧栏 / 设置导航。
