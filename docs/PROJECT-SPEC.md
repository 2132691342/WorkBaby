# docs/PROJECT-SPEC.md · 项目定位与功能范围

## 1. 项目定位

WorkBaby 是运行在 Windows 桌面的**个人 AI 助手**：不是聊天窗口，而是能在本机干活的 Agent。

| 维度 | 立场 |
|---|---|
| 形态 | Windows 桌面应用（Wails + WebView2），单进程内嵌 HTTP 服务 |
| 使用者 | 单个本机用户；无账号、无多租户、无云同步 |
| 数据 | 全部留在本机 `%APPDATA%\WorkBaby`；密钥 AES-256-GCM 加密 |
| 网络 | 除用户自己配置的模型服务与主动发起的联网工具外，不依赖任何云端 |
| 能力边界 | 读写你指定的工作区文件、执行白名单内命令、检索本地知识库、调用技能与 MCP 工具；需要授权时停下来问 |

**与「聊天机器人」的本质差别**：每一次回答都可追溯到真实的工具调用与文件变更。声称「已创建文件」但本 run 没有对应写文件记录时，系统主动揭露（反幻觉核验）。

## 2. 产品目标

| 目标 | 落地方式 |
|---|---|
| 能干活 | 33 个内置工具覆盖文件 / 命令 / 网络 / 文档 / 知识库 / 记忆 / 计划 / 委派 |
| 干得可见 | 过程块（思考 / 工具 / 正文）按真实顺序落库；工具卡展示活动描述、耗时、实际工作目录、失败计数 |
| 干得可控 | 权限四档 + 审批门 + 目录信任 + 命令白名单 + 用户钩子五层护栏；拒绝是回执而非错误，模型可改道 |
| 干得可续 | 检查点续跑、跨重启恢复（审批暂停后关掉应用再回来，决策仍在）、目标模式自动推进 |
| 干得省心 | 上下文自动压缩、长任务后台化、token 用量与成本可查、分段耗时归因 |
| 私有 | 本地存储、本地检索、本地模型可选（Ollama）、密钥加密 |

**不做**：多用户 / 团队协作、云端同步、移动端、非 Windows 桌面平台、付费计费、向量数据库。

## 3. 功能范围

### 3.1 对话与 Agent

| 功能 | 说明 |
|---|---|
| 多会话 | 置顶 / 归档 / 搜索 / 清空 / 压缩；会话可绑定本地工作区目录 |
| 一次对话 = 一次 run | ReAct 循环（模型 ↔ 工具），流式输出，随时中断 |
| 断线重放 | 事件带单调 seq，SSE 断线后按 `last_event_id` 重放；窗口溢出下发 `chat:gap` 转全量 |
| 检查点续跑 | 中断/崩溃后从检查点恢复，已完成工具调用不重放副作用 |
| 插话纠偏 | run 进行中插入用户消息，在轮间（steering）或收尾（follow-up）缝消费 |
| 委派子 Agent | `delegate_task`：上下文 / 预算 / 工具 / 正文四重隔离，只回传摘要 |
| 后台任务 | 提交即返回，后台跑完出结果，可取消，跨重启可见 |
| 目标模式 | 设定目标后逐轮推进，每轮结束按实据校验，未达成自动续跑 |
| 计划模式 | 只读探索阶段，写/执行工具硬拦；退出经审批 |
| 待办与补问 | `todo` 会话待办；`request_input` 缺关键信息时向用户提问并阻塞等待 |

### 3.2 工具能力

| 分组 | 工具 |
|---|---|
| 文件 | `file_read` `file_write` `file_edit` `file_list` `file_grep` `file_glob` `archive_manager` |
| 命令 | `exec`（白名单内二进制，参数数组无 shell 拼接，输出双端限流） |
| 网络 | `websearch`（DuckDuckGo 免 Key）`webfetch` `http`（仅 GET/POST） |
| 文档 | `doc_reader`（pdf/docx/html/csv/json/txt/md） |
| 检索 | `knowledge_search`（本地知识库唯一入口，返回带出处片段） |
| 记忆 | `memory_write`（模型主动追加长期记忆） |
| 计划 | `todo` `enter_plan_mode` `exit_plan_mode` |
| 交互 | `request_input` |
| 技能 | `run_skill_script` |
| 委派 | `delegate_task` |
| 纯函数 | 12 个 functools（数学/日期/文本/正则/JSON/CSV/哈希/编码/随机），无 IO，默认分组禁用 |
| 外接 | `mcp_*`（来自 MCP 服务器） |

### 3.3 安全

| 层 | 机制 |
|---|---|
| 权限四档 | `restricted / default / auto_edit / yolo`，会话级可覆盖全局 |
| 工具策略门 | 风险 × 模式 × 规则 × 人工审批；`destructive` 恒需审批 |
| 审批持久化 | 未决记录落库；重启后重武装（窗口延至 24h），决策仍可下 |
| 免审授权 | 「本会话允许」落库跨重启生效；run 失败/取消时回滚 |
| 目录信任 | 未登记目录首次写入前询问（fail-closed），祖先信任可继承 |
| 工作区沙箱 | 文件工具限定工作区根；`exec` 的 cwd 越界校验；过程数据落 `.workbaby/` |
| 提示注入检测 | 参数含伪工具调用标记（`<tool_call>` 等）直接拒绝 |
| 用户钩子 | 七类生命周期事件可放行 / 询问 / 拦截 |

### 3.4 个性化与桌面

| 功能 | 说明 |
|---|---|
| 自定义子智能体 | 人设 / 工具策略 / 预算 / 模型 |
| 自定义斜杠命令 | 用户定义的提示词模板 |
| 技能 | 全局 / 工作区两级 + 内置；注入方法论与工具白名单 |
| 桌宠 | 跟随 Agent 状态（idle/happy/working/sleeping）；点击穿透 |
| 系统托盘 | 显示/隐藏、桌宠形态切换、退出 |
| 单实例 | 命名互斥 + 本地 TCP IPC；第二次启动唤起已有实例 |
| 关闭到托盘 | 可配置 |

## 4. 关键设计取舍

| 取舍 | 选择 | 优势 | 代价 |
|---|---|---|---|
| Agent 编排 | 显式 for 循环 + 护栏中间件链，不引入图引擎 | 全部状态在一处，可读可测；单 ReAct 场景零抽象开销 | 复杂拓扑（并行分支/子图）需自行扩展 |
| 上下文压缩 | 确定性折叠（不调 LLM） | 零成本零延迟、可预测、不引入额外失败点 | 摘要质量低于 LLM 摘要 |
| 业务通道 | HTTP + SSE，而非全走 Wails 绑定 | 浏览器原生可调试、可 curl 复现、可重放 | 需自建端口发现与契约校验 |
| 存储 | SQLite 单文件 + 连接数固定 1 | WAL + 单连接规避写锁竞争，桌面单用户最简单 | 写吞吐受限；长查询阻塞写 |
| 记忆 | 一份 Markdown + FTS5 派生索引 | 人可直接编辑；索引丢了重建即可 | 无向量语义检索 |
| 权限 | 拒绝 = 结构化回执（`Refused`）而非错误 | 模型读到原因可改道，不整轮失败 | 每个工具必须正确区分「拒绝」与「失败」 |
| 事件出口 | 单一 `Emitter`（归属 + seq + 广播） | 前端契约形状唯一；重放与序号只在一处保证 | 所有业务域必须走它 |
