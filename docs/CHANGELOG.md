# 更新日志

## 2026-11-16

问题编号（`A` 安全 / `S` 稳定性 / `F` 功能，如 `S2`、`F1`）对应 `docs/AUDIT-2026-11-16.md` 的问题清单。
条目按主题分组，组内按提交先后**从新到旧**排。

### 安全

- **危险命令确认闸门**（`A4`）：`bash` 命中危险特征（递归删除 / 格式化 / 注册表写入 / 停机重启 / 磁盘擦除）
  先弹确认卡，拒绝或无确认通道一律不执行；设置键 `agent.bash_confirm` 可关（默认开，fail-closed）。
- **令牌与来源门禁收紧**（`A5`）：发布版禁用 `WB_DEV_TOKEN`（仅开发态布局接受）；熵源失败直接拒启；
  Host 白名单只认回环主机名（DNS rebinding 纵深）；查询参数令牌只允许 `/events` 一条路由；
  令牌比较改常量时间。
- **`/config/text` 密钥掩码**（`A2`）：设置台账预览对密钥键走与 `/settings` 同一套掩码，
  解不开的 JSON 整份不给；模型探测错误原话脱敏，google 协议密钥改走请求头不进 URL。
- **渲染出口统一接 DOMPurify**（`A1`）：Markdown 渲染出口消毒（禁 `script` / `iframe` / `style` / `form`
  与事件属性），模型输出与抓回的网页不再能往 WebView2 注入脚本。
- **写入口越权收口**：设置入口写不进工作区键（`workspace.current` / `workspace.history` 为保留键）；
  会话删除、模板命名补守卫；路径守卫能挡符号链接。

### 稳定性

- **grep / PDF 资源上限**（`S13` 半边）：`grep` 单文件超 1MB 跳过；PDF 全部流解压累计预算 64MB
  （单流上限 32MB 不变），单流上限乘上千个流不再是解压炸弹。
- **SSE 泵收摊即断连**：`Hub.Subscribe` 返回 done 通道、广播入队与发号同锁（防 seq 乱序）；
  慢订户摘号后 HTTP 层立刻结束连接，客户端带 `since` 重连补帧，不留只有心跳的僵尸连接；
  `queryInt64` 改 `strconv.ParseInt` 防手写累加静默溢出。
- **索引重建可取消、检索与记账同锁**（`S4`）：`index.Build` 接收 ctx、遍历中检查取消；
  `Searcher.Search` 全程持锁，不会读到半新半旧的索引；构建中且无索引回 `5002` 可读错误。
- **MCP 先装新后收旧**（`S9`）：重建时先把新工具段装上注册表再收旧进程，
  装载窗口里全部 MCP 工具不再凭空消失；MCP 请求等待支持取消。
- **工具结果全文落盘、裁窗孤儿修复**（`S2`）：落盘存全文，折叠只发生在组装上下文时——
  「展开看全文」回放后不再只剩折叠文本；`trimToWindow` 之后修复孤儿 tool 消息
  （孤儿丢弃、悬空 tool_call 补占位），长对话不再被严格上游整条拒掉。
- **length 截断整批拒绝**（`S5`）：输出被 `max_tokens` 截断时整批工具不执行，
  半截 JSON 入参不再喂给写工具。
- **上游退避重试**（`S6`）：建流失败与流内错误按白名单指数退避（2s / 4s / 8s × 3），
  鉴权失败一票否决不重试、abort 不重试；广播 `chat:retry` / `chat:retry_end`。
- **排队丢消息窗口收口**（`S10`）：`Steer` / `FollowUp` 取 runner 与入队进同一临界区，
  运行恰在收尾时消息不再排进无人消费的队列。
- **工具调用分片同 index 只补空字段**（`S1`）：上游把 name 分片下发或同 index 重复带 id 时
  不再整块覆盖，已拼进去的入参前缀不再被清掉。
- **Frecency 加互斥锁**（`S3`）：界面检索（HTTP 协程）与模型 `index_search`（运行协程）
  并发读写同一份 map 不再触发进程级崩溃。
- **上游流空闲看门狗**（`S11`）：90s 帧间无数据即关流断开；行长按块累计，
  无换行的大行不再先攒进内存再检查上限。
- **子进程取消透传**：git / 注册表 / MCP 探测等调用统一透传 ctx，取消即杀进程树，不等满超时。

### 功能修复

- **patch 字段统一**（`F5`）：前端 `readPatch` 改读 `kind`（后端 `chat:patch` 载荷一直是它），
  流式增量不再全部落成 text 块。
- **当前会话可改名 / 删除**（`F2`/`F3`）：改名经 `Chat.RenameAny` 走引擎写锁追加，
  删除经 `Chat.PrepareDelete` 先中止运行、切新会话再删，不再对引擎打开的会话回 `5002`。
- **MentionSessions 死代码删除**（`F8`）：前端直读 `ui.mention_sessions` 键，保存入口收敛 1~20。
- **提问卡刷新可恢复**（`S8`）：`ask_pending` 进 `/chat/state`，刷新界面据此补回待答卡。
- **`/export` 消费分支**（`F4`）：导出自包含 HTML，不再直发给模型（语义见「行为变化」）。
- **base_url 统一拼接**（`F1`）：新增 `pkg.NormalizeApiBase` / `pkg.OpenAIEndpoint`，
  带不带 `/v1` 的填写都收敛到同一个真实端点，探测与聊天同口径——
  一头拼 `/chat/completions`、一头拼 `/v1/models` 的矛盾消除。
- **模型探测带取消**（`S14`）：探测接收请求 ctx，界面取消 / 退出后不再挂满 20s。
- **技能正文写保护收口**（`S7`）：写类工具对技能文件两层判定（入参原文 + 解析后含真实路径 /
  大小写变体），相对路径与符号链接绕不过去；改技能只走技能页。
- **中止与半截消息收尾**：中止时未执行的调用补「已中止」结果，半截消息里的 tool_calls 一并补取消结果；
  `notifyText` 不再吞空白增量（换行与缩进不丢）。
- **全站交互反馈与空态**：各页补空态、加载态与错误反馈，取数失败不再画成空清单；
  修失效令牌与 i18n 缺项；删掉被新基元取代的组件。
- **技能索引进系统提示**：每轮把「名字 — 一句话说明 — 路径」列进系统提示，正文按需 `read`。

### 行为变化

- **工作区配置目录 `.pi` → `.workbaby`**（`F9`）：旧 `.pi` 存在且新目录不存在时一次性整体搬迁，
  失败沿用旧目录并记日志；skills / mcp 三处路径全部收口到统一入口。
- **计划模式放行 `index_search`**（`F7`）：检索进只读白名单，计划模式下可以先调研；
  `bash` 仍全禁、MCP 工具仍全拦（`docs/USER-GUIDE.md` §5 有完整口径）。
- **`/export` 语义**：手输 `/export` 由后端消费，导出**自包含 HTML**；命令菜单里的 `export`
  仍是前端的 **Markdown** 导出——两条语义并存，界面上分得开（`docs/USER-GUIDE.md` §8 / §13）。
- **危险命令新增确认闸门**（默认开）：命中危险特征的命令执行前先要一次确认；
  经 `agent.bash_confirm` 置 `"0"` 可关（`docs/USER-GUIDE.md` §6）。
- **发布版忽略 `WB_DEV_TOKEN`**：令牌每启动随机（24 字节熵），熵源失败拒启；
  固定令牌只在开发态布局可用（`docs/DEV.md` §2.4）。
- **工具结果全文落盘**：会话文件里工具结果存全文，折叠文本只在组装上下文时产生——
  「展开看全文」回放恢复真实全文。
