# 14 · 构建与分发

## 开发运行

```
wails dev            # 前后端热重载（前端 5173，后端内嵌 HTTP 随机端口）
wails build          # 生产构建
wails build -nsis    # 构建并打安装包
```

推荐的生产命令（体积更小、路径更干净）：

```
wails build -nsis -ldflags "-s -w" -trimpath
```

## 构建流水线

`wails.json` 定义：

| 项 | 值 |
|---|---|
| `frontend:install` | `npm install`（在 `frontend/` 下） |
| `frontend:build` | `npm run build` → `vue-tsc -b && vite build`，产物 `frontend/dist` |
| `outputfilename` | WorkBaby |
| `wailsjsdir` | `./frontend/src`（生成的绑定放这里） |
| `postBuildHooks`（windows/amd64） | `scripts/copy-runtimes.ps1 ${bin}` |

前端产物由 `main.go` 的 `//go:embed all:frontend/dist` 编进二进制，运行时经 AssetServer 提供；`/files/**` 前缀转发到本地受管文件服务。

`copy-runtimes.ps1` 把 `runtimes/`（manifest + python / powershell 归档）复制到产物目录与 `build/windows/runtimes`，清单声明的归档缺失即构建失败。

## 版本号

单一来源 `wails.json` 的 `info.productVersion`（当前 0.1.0）→ NSIS `INFO_PRODUCTVERSION` → 可执行文件版本资源。前端 `package.json` 保持同版本。界面「版本」由 `GET /api/v1/meta/runtime` 提供。

## 安装包

NSIS 脚本在 `build/windows/installer/project.nsi`（配 `wails_tools.nsh`、图标 `build/windows/icon.ico`、`info.json`）。产物：

- `build/bin/WorkBaby.exe`（便携版）
- `build/bin/WorkBaby-amd64-installer.exe`（安装包）

文件关联：`.md / .txt / .pdf` 双击可唤起 WorkBaby（配合单实例的 IPC 传路径）。

## 运行时目录

数据根目录 `%APPDATA%\WorkBaby`（可用 `WORKBABY_HOME` 覆盖），结构：

```
config.yaml            主配置（含主密钥）
db/workbaby.db         SQLite（WAL）
logs/                  按等级分流的日志（10MiB×5 轮转）
runs/                  run 事件 JSONL（最近 50 个）
skills/                全局技能
sprites/               桌宠形象
memory/{sessionID}/    长期记忆
workspaces/{sessionID}/默认会话工作区
runtimes/{id}/{ver}/   内置运行时
files/                 受管文件
```

## 分发注意

- WebView2 运行时未安装时安装包会引导安装
- 首次启动生成主密钥（`config.yaml` 的 `security.master_key_b64`），密钥用它 AES-256-GCM 加解密；换机器或删配置会丢失已存密钥
- 全量卸载需同时清理 `%APPDATA%\WorkBaby`（工作区内的 `.workbaby/` 沙箱不在其中）
