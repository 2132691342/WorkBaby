# 05 · 工具系统

## 工具契约

```go
type Tool interface {
    Name() string
    Description() string
    Schema() ToolSchema                      // JSON Schema（draft 2020-12）
    RiskLevel() RiskLevel                    // readonly / write_local / exec / network / destructive
    Execute(ctx, args json.RawMessage) ToolResult
}

type ToolResult struct {
    Content string
    Data    map[string]any
    Err     error             // 执行故障
    Meta    map[string]string
    Refused bool              // 被护栏拒绝（不是故障）
}
```

可选接口（实现了才启用对应能力，不破坏已有实现）：

| 接口 | 用途 |
|---|---|
| `MetaProvider` | 声明只读/破坏性、路径参数、超时、截断上限、UI 提示、分组、类别 |
| `ActivityProvider` | 生成「正在做什么」的活动描述 |
| `RiskClassifier` | 按**本次入参**给出命令级风险描述与级别（exec / 技能脚本用） |

## 注册表

`tool.Registry`：`Register`（重名 4005；schema 编译失败 4004，**注册即编译**）、`Unregister`（MCP 服务器停用时移除）、`Get`、`List`、`AllReadOnly`（只读并发裁决）、`SelfCheckSchema`（启动期自检，不合法直接启动失败）。

工具启停不在注册表，由 `service.ToolService` 结合 `system_settings` 决定（键：`SettingKeyToolEnabledPrefix + 工具名`）。

参数校验用 `santhosh-tekuri/jsonschema/v6`，资源 URL 走自定义 scheme `workbaby://`，并剥离 MCP 带来的 `$schema`（避免启动期联网拉元 schema）。

## 内置工具

| 分组 | 工具 | 能力 |
|---|---|---|
| 文件 | `file_read` `file_write` `file_list` | 读 / 覆盖写（≤2MB）/ 列目录，路径限定工作区沙箱 |
| 文件 | `file_edit` | 精确字符串替换，要求唯一匹配，回执带 unified diff |
| 文件 | `file_grep` `file_glob` | 正则内容检索（含行号）/ 通配列文件，尊重 .gitignore |
| 文件 | `archive_manager` | zip 压缩与解压（工作区相对路径） |
| 命令 | `exec` | 白名单内二进制，参数数组（无 shell 拼接），输出头 120KB + 尾 80KB 双端限流 |
| 网络 | `websearch` `webfetch` `http` | 网页搜索（默认 DuckDuckGo，免配置）/ 抓正文（≤5MB）/ 通用请求（仅 GET/POST） |
| 文档 | `doc_reader` | 抽取 pdf/docx/txt/md/html/csv/json 纯文本 |
| 检索 | `knowledge_search` | 本地知识库检索唯一入口，返回带出处的片段 |
| 记忆 | `memory_write` | 模型主动追加一条长期记忆 |
| 计划 | `todo` `enter_plan_mode` `exit_plan_mode` | 会话待办 / 计划模式进出（退出走审批门） |
| 交互 | `request_input` | 缺关键信息时向用户提问并阻塞等待 |
| 技能 | `run_skill_script` | 运行技能内置脚本（解释器固定映射，2 分钟超时） |
| 委派 | `delegate_task` | 委派子 Agent |
| 纯函数 | 12 个 functools | 数学/日期/文本/正则/JSON/CSV/哈希/编码/随机，无 IO 无副作用，默认分组禁用 |
| 外接 | `mcp_*` | 来自 MCP 服务器 |

所有工具在 `api.Handler.Startup` 中注册，能力注册表暴露的工具（`knowledge_search` / `memory_write`）与 functools 一并注册，最后统一 `SelfCheckSchema`。

## 命令执行与风险裁决

`DefaultExecPolicy`：白名单按 basename（`cmd / powershell / git / go / node / npm / python / java / make / curl …`），危险正则 13 条（`rm -rf`、`del /s`、`format`、`diskpart`、`shutdown`、`taskkill /f` …）。

`ExecTool.ClassifyArgs` 做**命令级**裁决（而不是工具级）：

- 白名单内的安全命令 → 免审
- 命中危险正则 → `irreversible`（必须人工批准）
- 白名单外 → `needs_approval`
- 空命令 → 无风险

运行时白名单可被 `system_settings` 的 `SettingKeyExecWhitelist` 覆盖；`WithSandbox` 校验 cwd 越界（含 `..` 报 4007，越出工作区报 4008）；内置运行时目录前置到子进程 PATH。

## 目录与身份

工具需要知道「自己在哪个会话、哪次 run、工作区在哪」：`tool.WithRunIdentity(ctx, runID, sessionID)` 注入，`RootResolver(sessionID) string` 解析工作区根。绑定目录时 `file_write` / `exec` 都落在绑定目录，未绑定时落在默认工作区。

## 写前必读

`file_edit` 要求目标文件在本 run 内先被读过（`readtrack`），防止模型凭空改写未确认内容。

## 用户钩子

用户可配置脚本在工具调用前后与 run 边界裁决，扩展内置护栏之外的规矩。

**事件**（归一为六类）：`SessionStart / UserPromptSubmit / PreToolUse / PermissionRequest / PostToolUse / PostToolUseFailure / Stop`（`PermissionRequest` 仅当权限结果需要询问时触发）

**匹配式**三种写法：`""` 或 `*` 匹配全部；只含字母数字下划线与竖线按精确名称名单（非子串）；含其他字符按正则。非法正则在**写入期**即拒绝——落库后才失效会让钩子静默不生效。

**子进程协议**：脚本从 stdin 收 JSON 事件，从 stdout 回 JSON 决策：

- `hookSpecificOutput.permissionDecision`：`allow / deny / ask`
- `decision.behavior` 形态同样支持（`deny` + `message`）
- `additionalContext`（或下划线别名 `additional_context`）并入回执
- 退出码 2 等价拒绝；非 JSON 输出忽略；噪声日志中取 JSON 行

**Stop 续跑**：`Stop` 事件返回 `block` 且带理由（或退出码 2 带理由、或 `continue: true` 带附加上下文）时，Agent 据此继续下一轮，最多续 3 次——这让「没跑测试就不许停」这类规矩可执行。

钩子故障不阻断：执行器内部兜底放行。
