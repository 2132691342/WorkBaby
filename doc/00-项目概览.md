# 00 · 项目概览

## 是什么

WorkBaby 是运行在 Windows 桌面的个人 AI 助手。它不是一个聊天窗口，而是一个**能在本机干活的 Agent**：可以读写你指定的工作区文件、执行白名单内的本机命令、检索本地知识库、调用自定义技能与 MCP 工具，并在需要授权时停下来问你。

全部数据（会话、记忆、知识库、配置、密钥）存放于本机 `%APPDATA%\WorkBaby`，密钥用本机主密钥 AES-256-GCM 加密。除用户自己配置的模型服务外，不依赖任何云端。

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 桌面壳 | Wails v2 | Go 与 WebView2 混合：系统能力（窗口/托盘/对话框）走 Wails 绑定，业务 API 走本机 HTTP |
| 后端 | Go 1.24 · gin · gorm | 单进程，内嵌 HTTP Server 监听 `127.0.0.1` 随机端口 |
| 存储 | SQLite（pure-Go，WAL） | 26 张业务表 + 2 张 FTS5 虚拟表（trigram 分词，解决中文检索） |
| LLM | 自研适配层 | OpenAI / Anthropic / Ollama 三种协议，流式、工具调用、思维链归一化 |
| Agent | 自研内核 `internal/core` | 显式 ReAct 循环 + 护栏中间件链，无第三方编排框架 |
| 前端 | Vue 3 · TypeScript · Vite · Element Plus | Pinia 状态、Tailwind + 自研玻璃拟态设计令牌 |
| 实时通道 | SSE | 事件带单调序号，支持断线重放 |

## 能力清单

**对话与 Agent**
- 多会话（置顶/归档/搜索/清空/压缩），会话可绑定本地工作区目录
- 一次对话 = 一次 `run`：ReAct 循环（模型 ↔ 工具），流式输出，随时中断
- 委派子 Agent（`delegate_task`）：上下文、预算、工具、正文四重隔离
- 后台任务：提交即返回，后台跑完出结果，可取消，跨重启可见
- 目标模式：设定目标后逐轮推进，可暂停/恢复
- 计划模式、待办（todo）、补问（request_input）

**干活的工具**（见 [05-工具系统](05-工具系统.md)）
- 文件：读 / 写 / 编辑 / 列目录 / 检索 / 打包，限定在工作区沙箱内
- 命令：`exec` 白名单内二进制 + 危险模式拦截 + 命令级风险裁决
- 网络：网页搜索、网页抓取、通用 HTTP（仅 GET/POST）
- 文档：pdf/docx/html/csv/json 抽取正文（前端再经 SheetJS / docx-preview / vue-pdf-embed 渲染）
- 知识库检索、长期记忆写入、技能脚本执行
- 12 个纯函数工具（数学 / 日期 / 文本 / 正则 / JSON / CSV / 哈希 / 编码 / 随机），无 IO 无副作用，默认分组禁用
- MCP：外接任意 stdio MCP 服务器，工具以 `mcp_` 前缀暴露
- 总计 **33 个内置工具**（15 个域 × 子工具）

**安全**
- 权限四档：restricted / default / auto_edit / yolo
- 工具策略门：风险 × 模式 × 规则 × 人工审批
- 审批可暂停可恢复（durable pause）：关掉应用再回来，未决审批仍在
- 目录信任：工作区外的目录首次使用时询问
- 用户钩子：自定义脚本在工具调用前后裁决

**个性化**
- 自定义子智能体（人设/工具策略/预算/模型）
- 自定义斜杠命令、用户级与工作区级技能
- 知识库（文件/URL/文本）
- 桌宠：跟随 Agent 状态变化，可切窗口形态与点击穿透
- 系统托盘、单实例、关闭到托盘、文件关联打开

## 关键设计取舍

| 取舍 | 选择 | 理由 |
|---|---|---|
| Agent 编排 | 自研显式循环，不引入图引擎 | 单 ReAct 循环用不到 DAG；显式循环可读、可测、可控 |
| 护栏 | 中间件链（函数组合） | 每个安全关注点一件，顺序即语义，加规则不改循环 |
| 拒签语义 | 拒绝是 `Refused` 回执，不是错误 | 模型能读到拒绝原因并改道，而不是整轮失败 |
| 上下文压缩 | 确定性折叠，不调 LLM 摘要 | 零成本、零延迟、可预测，不引入额外失败点 |
| 业务通道 | HTTP + SSE，而非全走 Wails 绑定 | 浏览器原生可调试、可重放；Wails 只承载系统能力 |
| 记忆 | 一份 Markdown + FTS5 派生索引 | 人可直接编辑，索引丢了重建即可 |
| 存储 | SQLite 单文件，连接数固定 1 | 单机单用户，WAL + 单连接彻底规避写锁竞争 |
| 流式可靠性 | 单调序号 + 重放 + gap 转全量 | 断线不丢终态，缓冲被覆盖时明确告知而非静默 |
