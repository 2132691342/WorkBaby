# 00 · 项目概览

## 是什么

WorkBaby 是运行在 Windows 桌面的**个人 AI 助手**：不是聊天窗口，而是能在本机干活的 Agent——
读写你指定的工作区文件、执行白名单内的本机命令、检索本地知识库、调用技能与 MCP 工具，
需要授权时停下来问你。

全部数据（会话 / 记忆 / 知识库 / 配置 / 密钥）落在本机 `%APPDATA%\WorkBaby`，密钥用本机主密钥
AES-256-GCM 加密。除用户自己配置的模型服务外，不依赖任何云端。

## 技术栈

| 层 | 选型 | 选择理由 |
|---|---|---|
| 桌面壳 | Wails v2 | Go 与 WebView2 混合：系统能力（窗口/托盘/对话框）走原生绑定，业务 API 走本机 HTTP——**浏览器可调试、可 curl 复现**，不需要为每个功能写 IPC |
| 后端 | Go 1.24 · gin · gorm | 单进程内嵌 HTTP Server，监听 `127.0.0.1` 随机端口；Go 的并发模型直接承载「多会话并行 run + 工具并行执行」 |
| 存储 | SQLite（pure-Go，WAL） | 单文件、零部署、事务完备；trigram 分词 FTS5 解决中文检索 |
| LLM | 自研适配层 | OpenAI / Anthropic / Ollama 三协议，流式、工具调用、思维链归一化为统一消息模型 |
| Agent | 自研内核 `internal/core` | 一个 for 循环 + 5 个钩子 + 事件流；不引入图引擎（见下"取舍"） |
| 前端 | Vue 3 · TS · Vite · Element Plus | Pinia 状态 + 自研玻璃拟态设计令牌（`--wb-*`） |
| 实时通道 | SSE | 事件带单调序号，支持断线重放；订阅维度是**会话** |

## 能力清单

**对话与 Agent**
- 多会话（置顶/归档/搜索/清空/压缩），会话可绑定本地工作区目录
- 一次对话 = 一次 `run`：ReAct 循环（模型 ↔ 工具），流式输出，随时中断
- 断线重放、检查点续跑、跨重启恢复（审批暂停后关掉应用再回来，决策仍在）
- 委派子 Agent（`delegate_task`）：上下文/预算/工具/正文四重隔离
- 后台任务：提交即返回，后台跑完出结果，可取消，跨重启可见
- 目标模式：设定目标后逐轮推进，每轮结束校验实据，未达成自动续跑
- 计划模式、待办（todo）、补问（`request_input`）

**干活的工具**（详见 [05-工具系统](05-工具系统.md)）
- 文件：读/写/精确编辑/列目录/正则检索/通配查找/打包，限定在工作区沙箱内
- 命令：`exec` 白名单内二进制 + 危险模式拦截 + 命令级风险裁决
- 网络：网页搜索（DuckDuckGo 免 Key）、抓正文、通用 HTTP（仅 GET/POST）
- 文档：pdf/docx/html/csv/json 抽取正文
- 知识库检索、长期记忆写入、技能脚本执行、MCP 外接工具

**安全**
- 权限四档：`restricted / default / auto_edit / yolo`
- 工具策略门：风险 × 模式 × 规则 × 人工审批（拒绝是回执而非错误，模型能改道）
- 审批可持久化：关掉应用再回来，未决审批仍在
- 目录信任、工作区沙箱、提示注入检测、用户钩子（自定义脚本裁决）

**个性化**
- 自定义子智能体（人设/工具策略/预算/模型）、自定义斜杠命令、技能（全局/工作区两级）
- 知识库（文件/URL/文本）、长期记忆（单一 MEMORY.md + FTS5 索引）
- 桌宠（跟随 Agent 状态）、系统托盘、单实例、关闭到托盘、文件关联打开

## 关键设计取舍

| 取舍 | 选择 | 优势 | 代价 |
|---|---|---|---|
| Agent 编排 | 自研显式 for 循环，不引入图引擎 | 可读、可测、可控；一个 run 的所有状态都在一处 | 复杂拓扑（并行分支/子图）需要自己写；不适合工作流编排 |
| 上下文压缩 | 确定性折叠（不调 LLM 摘要） | 零成本、零延迟、可预测；压缩不引入额外失败点 | 摘要质量低于 LLM 摘要；跨轮语义衔接靠占位说明 |
| 业务通道 | HTTP + SSE，而非全走 Wails 绑定 | 浏览器原生可调试、可重放；前端可独立用 curl 复现问题 | 需要自建端口发现与契约校验（`app:ready` 注入端口） |
| 存储 | SQLite 单文件 + 连接数固定 1 | WAL + 单连接彻底规避写锁竞争，桌面单用户场景最简单 | 写吞吐受限（并发写串行）；不适合多用户 |
| 实时可靠性 | 单调 seq + 重放 + gap 转全量 | 断线不丢终态；缓冲被覆盖时明确告知而非静默 | 内存中保留每 run 的事件缓冲（有上限） |
| 事件出口 | 单一 `Emitter`（归属 + seq + 广播） | 前端契约形状唯一；重放与序号只在一处保证 | 所有业务域必须走它，绕过即失去重放能力 |
| 记忆 | 一份 Markdown + FTS5 派生索引 | 人可直接编辑；索引丢了重建即可 | 无向量语义检索（靠 FTS + 短查询兜底） |
| 权限 | 拒绝 = 结构化回执（`Refused`）而非错误 | 模型读到原因可改道，不整轮失败 | 需要每个工具正确区分「拒绝」与「失败」 |
