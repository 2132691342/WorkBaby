# 12 · 桌宠

桌宠是一个独立的小窗口，跟随 Agent 状态变化，用于「不占主窗口也能看到它在不在忙」。

## 状态机

`pet.Controller` 状态：`idle / happy / working / sleeping`

| 事件 | 迁移 |
|---|---|
| `agent.run.start` | → working |
| `agent.run.done` | → happy，3 秒后自动回 idle |
| `agent.error` | → idle |
| 用户闲置 30 分钟 | → sleeping |
| 用户活动 | → idle |

状态变化回调 emit `pet:state`，前端据此切换形象。状态相同不重复回调。

## 形象

- 内置形象编译期嵌入（`assets/workbaby.png`），首次启动播种为默认选中
- 用户可上传：magic number 识别 png/jpg/gif/webp（防扩展名伪装），≤5MB，落盘 `{home}/sprites/{id}{ext}`
- 读取走 `/files/sprites/{id}`：WebView2 不能直接读 `file://`，需要经本地文件服务；上传时后端把本地图片转成 data URL

## 窗口

两种形态：主窗口态（≥960×640）与桌宠态（260×300，可置顶、可移动）。切换时记忆主窗口位置尺寸并还原。

点击穿透：桌宠态下用 Win32 `CreateRectRgn` + `CombineRgn` 设置命中区域（最多 64 个矩形），未覆盖区域鼠标穿透到下面的窗口；清空区域即恢复可点击。

## 装配

`api.Handler` 订阅 `chat:` 前缀事件驱动控制器；托盘菜单项「召唤·收起桌宠」直接切换形态；窗口尺寸与位置经 Wails 运行时接口设置。

## 取舍

| 取舍 | 优势 | 代价 |
|---|---|---|
| 桌宠是主窗口的一种形态（单窗口切换） | 无需多窗口架构；与主应用共享同一前端上下文与状态 | 无法与主窗口同时显示（多窗口需 Wails v3） |
| 事件驱动（订阅 `chat:*` 驱动状态机） | 姿态与 Agent 状态天然一致，无需额外轮询 | 依赖事件时序（订阅端需容错，缺事件时回落 idle） |
| 点击穿透 + 命中区域上报 | 不遮挡用户操作 | 命中判定依赖前端上报，存在平台/DPI 差异 |
| 形象资产本地托管（`/files/sprites`） | 与头像、聊天背景同源，用户只传一张 | 依赖本地 HTTP 服务可用（未就绪时静默回退内置 SVG） |
