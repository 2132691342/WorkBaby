# WorkBaby 文档

WorkBaby 是一个 Windows 桌面个人 AI 助手：Go 后端（Wails + gin + gorm + sqlite）提供本地 Agent 能力，Vue3 前端提供交互，全部数据落在本机，不依赖云端。
