# WorkBaby 文档

WorkBaby 是一个 Windows 桌面个人 AI 助手：Go 后端（Wails + gin + gorm + SQLite）提供本地 Agent 能力，
Vue3 前端提供交互，全部数据落在本机，不依赖云端。

每篇文档的结构一致：**定位 → 设计 → 实现要点 → 取舍（优势与代价）**，只描述现状，
不记录改动过程。开发规范（分层约束、错误码、命名、测试要求）见仓库根 [CLAUDE.md](../CLAUDE.md)。
